Number Input parity — <lab-number-input> (Lit) ↔ <NumberInput> (React)

Two renderers, one @zag-js/number-input machine through the same seam. The machine owns the parsed value, min/max/step clamping, the role="spinbutton" + aria-valuenow/valuemin/valuemax/valuetext, Arrow/PageUp-Down keyboard stepping, and the +/- triggers that disable at the bounds. The label/helper/error wiring is computed by the SAME shared field-a11y helper on both renderers, and both paint the same --lab-* roles.
