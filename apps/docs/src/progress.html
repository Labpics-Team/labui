Progress parity — <lab-progress> (Lit) ↔ <Progress> (React)

Two renderers, one @zag-js/progress machine through the same seam. The machine owns the value→percent maths, role="progressbar" with aria-valuemin / aria-valuemax / aria-valuenow, and the determinate-vs-indeterminate state. Both modes are real: an indeterminate bar honestly drops aria-valuenow rather than faking a percent. This page mounts both so the Playwright suite can assert machine output and visual parity on each.
