Select parity — <lab-select> (Lit) ↔ <Select> (React)

Two renderers, one @zag-js/select machine through the same seam. The machine owns open-on-click, single/multiple selection, Arrow/Home/End navigation + typeahead, Escape / outside-click dismiss, focus restoration, role="combobox"/listbox/option + aria, and dynamic positioning. The Lit element keeps the listbox inside its shadow root (strategy:'fixed', portalled:false); the React twin portals it to <body>. Both paint with the same --lab-* roles.
