Combobox parity — <lab-combobox> (Lit) ↔ <Combobox> (React)

Two renderers, one @zag-js/combobox machine through the same seam. The machine owns open-on-focus/type, the filterable listbox, single/multiple selection, Arrow/Home/End navigation, Escape / outside-click dismiss, focus restoration, role="combobox"/listbox/option + aria-expanded/controls/activedescendant/autocomplete, and dynamic positioning. The typed query NARROWS the options (the consumer's shared filter). The label / helper / error association comes from the shared field-a11y helper, identical on both renderers. The Lit element keeps the listbox inside its shadow root (strategy:'fixed', portalled:false); the React twin portals it to <body>. Both paint with the same --lab-* roles.
