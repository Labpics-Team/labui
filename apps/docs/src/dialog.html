Dialog parity — <lab-dialog> (Lit) ↔ <Dialog> (React)

Two renderers, one @zag-js/dialog machine through the same seam. The machine owns open-on-click, focus move-in + restore-on-close, dismiss (Escape / outside-click), the modal focus-trap + scroll-lock + outside-content hiding. The Lit element PORTALS its floating layer to <body> and relocates the slotted body there; the React twin uses createPortal(body). Both make the modal trap REAL for the dialog body, and both paint with the same --lab-* roles.
