Pin Input parity — <lab-pin-input> (Lit) ↔ <PinInput> (React)

Two renderers, one @zag-js/pin-input machine through the same seam. The machine owns each box's value, the roving focus that auto-advances on type and steps back on Backspace, the paste-fill that distributes a code across the boxes, masking (type=password), the roving tabindex + per-box aria-invalid, and the complete event. The label / helper / error wiring is computed by the SAME shared field-a11y helper on both renderers (on the control group), and both paint the same --lab-* roles.
