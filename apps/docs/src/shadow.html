Shadow stack

Five elevation sizes — XS / S / M / L / XL — each exactly four plies, straight from the owner's styles. Fixed per-slot alphas; depth is geometry. Neutral by default; light is vertical. Light and dark are a variable swap, not a re-author.

In light, depth reads from the drop shadow. In dark — where a shadow has almost no contrast against a near-black page — depth reads from the surface: each level sits on a lighter surface than the one below it (the dark-theme elevation model), with the shadow as a secondary cue.

Light angle is fixed at 0° (vertical). It is a generator input — set --lab-light-angle before the ladder is emitted — not a runtime control.
