Tooltip parity — <lab-tooltip> (Lit) ↔ <Tooltip> (React)

Two renderers, one @zag-js/tooltip machine through the same seam. The machine owns the open lifecycle (hover/focus), Escape-to-dismiss, role="tooltip"/aria-describedby, and dynamic positioning. The Lit element keeps the floating layer inside its shadow root with strategy:'fixed'; the React twin portals it to <body>. Both paint with the same --lab-* roles.
