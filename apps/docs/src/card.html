Card parity — <lab-card> (Lit) ↔ <Card> (React)

Two renderers, one design system. Same variants (elevated / outlined / filled), same header / body / footer regions, same semantic --lab-* roles. Card is presentational — it carries no machine; both renderers render native <article> semantics. This page mounts both so the Playwright suite can assert structure and visual parity on each.
