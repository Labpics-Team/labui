Menu parity — <lab-menu> (Lit) ↔ <Menu> (React)

Two renderers, one @zag-js/menu machine through the same seam. The machine owns open-on-click, Arrow/Home/End navigation + typeahead, Escape / outside-click dismiss, focus restoration, role="menu"/menuitem + aria, and dynamic positioning. The Lit element keeps the menu inside its shadow root (strategy:'fixed', portalled:false); the React twin portals it to <body>. Both paint with the same --lab-* roles.
