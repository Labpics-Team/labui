Popover parity — <lab-popover> (Lit) ↔ <Popover> (React)

Two renderers, one @zag-js/popover machine through the same seam. The machine owns open-on-click, focus move-in + restore-on-close, dismiss (Escape / outside-click), the optional modal focus-trap, and dynamic positioning. The Lit element keeps the panel inside its shadow root (strategy:'fixed', portalled:false); the React twin portals it to <body>. Both paint with the same --lab-* roles.
