Первый кадр и обновления

CSS содержит готовую палитру. Runtime подключается только к области, где приложение меняет тему или передаёт известные цвета подложки.

import '@labui/colors/contract.css';
import { initializeColors, createThemeScope } from '@labui/colors/runtime';

await initializeColors();
const element = document.getElementById('theme-sample');
if (!element) throw new Error('Область темы не найдена');
const scope = createThemeScope(element);
const result = scope.update({ theme: 'dark', contrast: 'normal' });
// При удалении области:
scope.dispose();

Повышенный контраст усиливает непрозрачность текста и проверяет primary на переданных подложках. Видео и прозрачный материал не считаются измеренным фоном. При отказе сохраняется последнее применённое состояние.
