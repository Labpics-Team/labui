Input parity — <lab-input> (Lit) ↔ <Input> (React)

Two renderers, one design system. A single-line text field: a real <input> wired to a label, an optional helper, and an optional error via genuine ARIA (aria-describedby → helper/error, aria-invalid, aria-errormessage, aria-required). Input is presentational — @zag-js has no text-input machine; the native control owns value/caret/editing. The label/helper/error wiring is computed by the SAME shared field-a11y helper on both renderers, and both paint the same --lab-* roles.
