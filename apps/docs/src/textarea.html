Textarea parity — <lab-textarea> (Lit) ↔ <Textarea> (React)

Two renderers, one design system. A multi-line text field: a real <textarea> wired to a label, an optional helper, and an optional error via the SAME genuine ARIA as Input, plus the multi-line extras (rows, optional auto-resize). Presentational — @zag-js has no text-input machine; auto-resize is local view state computed from scrollHeight, not a machine. The label/helper/error wiring is the SAME shared field-a11y helper on both renderers.
