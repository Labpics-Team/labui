Slider parity — <lab-slider> (Lit) ↔ <Slider> (React)

Two renderers, one @zag-js/slider machine through the same seam. The machine owns the value, min/max/step, each thumb's role="slider" + aria-valuenow/valuemin/valuemax/valuetext, Arrow/Home/End/PageUp-Down keyboard stepping, pointer drag + track-click, multi-thumb collision, and a hidden input per thumb. The group label/helper/error wiring is computed by the SAME shared field-a11y helper on both renderers, and both paint the same --lab-* roles.
