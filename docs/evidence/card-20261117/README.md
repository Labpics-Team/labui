# Card

Источник — неизменённый master `6225:42443` и примеры `7101:51896`,
`7710:6190` из Lab UI v2.1. Прямой PNG и извлечённые свойства сохранены рядом.

Card сохраняет изображение, радиус 16 со smoothing 0.6 и отдельный Elevated
под текстом. Изображение продолжается под этим материалом. Content имеет
padding 24 и собственную высоту; дополнительная высота Card достаётся media:
master 400×294 = 200+94, примеры 400×400 = 306+94.

Lit и React используют один профиль, CSS и runtime формы/материала. Текстовая
анатомия включает heading, headingHint, description, caption, lowerCaption и
badge. Media/header/footer/default content сохраняют возможность композиции.
Карточка не становится кнопкой: действие остаётся отдельным Button/ссылкой.
Пользовательский media сохраняет естественную высоту; правило растягивания
авторского изображения относится к свойству image.

Geist 1.400 восстановлен по исходным контурам четырёх семейств; причина и
сравнение приведены в [проверке шрифтов](../fonts-20261117/README.md).
Line-height задан точной rem-длиной: округление отношения 12/14 ранее давало
11 px вместо 12 в WebKit. Подпись без заголовка не оставляет пустую группу.

Серверный HTML Lit содержит DSD, стили, текст и настоящее изображение.
Проверка задерживает весь клиентский JavaScript, затем разрешает hydration:
заголовок остаётся тем же DOM-узлом, размер — тем же. В этом опыте загружается
нужный font face напрямую: общий document.fonts.ready в WebKit ждёт отложенные
скрипты и потому не служит условием первого серверного кадра.

Headless Chromium/WebKit проверяют геометрию, изменение высоты, две темы и три
материала, узкую ширину/200% text, клавиатуру, свойства, reconnect, SSR/hydration.
Node ESM/CJS import и React SSR также прошли. Измерения и снимки получены с
production preview; дробное положение страницы перед снимком выравнивается,
размер компонента не меняется. Оптическое доведение общего Glass продолжается
отдельно; эти снимки не объявляют весь material renderer завершённым.

Независимое ревью `25b4d1d` подтвердило шрифты и исходный рендер, но нашло
четыре дефекта Card. Исправлены нулевая высота React media, скрытый Text node
после изменения его data, пустая растягивающаяся область media до hydration
и устаревшая справка. Отдельный SSR опыт теперь сравнивает координаты заголовка
и footer внутри фиксированной высоты 400, а не только размер внешнего элемента.
Новые примеры/проверки находятся в `_fixtures/card-content.html` и `card.spec.ts`.
