# Настройки пространства: сохранение и восстановление

Веб-сценарий сохраняет название, описание, почту и уведомления одной
асинхронной транзакцией IndexedDB. Успех показывается после `complete`.
Ошибка оставляет панель, ввод и действие для повтора; pending сохраняет
ширину кнопки и удерживает панель. Отмена сравнивает ревизию записи и
не затирает более новое сохранение другой вкладки. Соединение закрывается
после операции. Старое значение примера из localStorage читается при
отсутствии записи IndexedDB.

Композиция использует авторские Card и контролы. Из
[Linear Preferences](https://linear.app/docs/account-preferences) взяты
ясная группировка настроек и соотношение подписей с действиями;
геометрия, цвета и шрифт остаются
[Lab UI v2.1](https://www.figma.com/community/file/1527814209910933331/lab-ui-components-icons-guides-lab-ui-v2-1).
Оформление переключает текущую страницу; сообщение о сохранении относится
к параметрам пространства.

## Проверено 18 ноября

- После объединения Chip и Textarea: 125 браузерных проверок прошли.
  Пять проверок WebKit пропущены: два forced-colors сценария Chip,
  две проверки фактического шрифта через CDP и CDP reduced-transparency Input.
  Набор включает `experience`, `input`, `textarea`, `chip` и `fonts`.
- `experience.spec.ts`: 20 проверок Chromium/WebKit — ввод, отмена,
  сохранение, Undo, ошибка записи и повтор, недоступное хранилище,
  конкурирующее сохранение, pending, клавиатура и узкий экран с масштабом 200%.
- `fonts.spec.ts`: две проверки Chromium — фактически нарисованные глифы
  принадлежат встроенному Geist, включая кириллицу; отсутствие файла шрифта
  обнаруживается даже при неизменном CSS. Две WebKit-проверки пропущены,
  поскольку получение фактического шрифта использует Chromium CDP.
- Sheet: 18 проверок положений/жизненного цикла и четыре проверки живого
  изменения содержимого. Независимый probe подтвердил React/Lit, рост
  заголовка, ограничение viewport, прокрутку, уменьшение, resize и reopen;
  после стабилизации дополнительных кадровых вызовов нет.
- Общая сборка и типы всех пакетов прошли. Генератор адаптеров: 32 проверки;
  Solid: 11; Svelte: 10. Каталог сверяет 46 семейств и 103 ссылки на источник.
- Textarea из заново установленных архивов прошла четыре SSR-адаптера и React
  в Chromium/WebKit: начальный текст, разные серверные и клиентские счётчики,
  CRLF/CR/LF, ввод до гидратации, выделение, редактирование и reset.
  [Запись проверки](../textarea-20261118/packed.json).

## Граница результата

Независимое ревью подтвердило исправленную [Textarea](../../reference/textarea.md)
и [native Input/Textarea при 200%](../../../native/compose/evidence/input-20261118/README.md).
Поздняя загрузка шрифта не обрезает текст; fallback выполняет один замер
на ввод и не измеряет поле в покое. Нативный `field-sizing` не создаёт
вспомогательный элемент. Compose сохраняет прежнюю геометрию Input при 100%.
Интеграция Icons в сам сценарий ещё требуется. Первый законченный опыт,
полный каталог и выпуск этой проверкой не объявляются завершёнными.

Снимки от 17 ноября — [архив](../experience-20261117/README.md).
Актуальный рендер: `node tests/experience-render.mjs <preview-url>` из
`apps/docs`; третий необязательный аргумент задаёт абсолютную папку вывода.
