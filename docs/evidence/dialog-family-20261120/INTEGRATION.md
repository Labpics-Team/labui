## Уточнение после независимого ревью Colors

Ревью `ffed6ca1` выявило ложные исключения при затенении имени, мутации через
alias/`Object.assign`/неизвестную функцию и сокращении `p.radius * 0 + 77`.
Имя теперь связано с декларацией через TypeScript symbol; локальные объекты
не считаются статическими, а escape или изменение профиля снимает доказательство.
Размерное исключение ограничено прямым полем и ненулевым масштабированием.
Реальные компоненты не менялись. Контрпримеры включают также блоки, callback,
переопределённый built-in, экспорт и destructuring-записи.
После исправления: Colors 291/291 (5,34 с), typecheck, Biome четырёх изменённых
TS-файлов и `git diff --check` прошли. Binding создаётся лениво только при
проверке интерполяций; первый вариант с binding в проходе комментариев занимал
8,22 с. Runtime и generated-артефакты этим исправлением не затронуты.

Повторное ревью `1e534ba4` подтвердило закрытие прежних случаев и выявило ещё
два: неизвестный initializer неиспользуемого параметра и запись через `as`/`!`.
Initializer теперь отменяет доказательство всего вызова; defaults/rest внутри
destructuring остаются неизвестными. Все поддержанные TypeScript-обёртки
обрабатываются общим predicate при чтении и записи. После контрпримеров:
Colors 303/303 (6,34 с), typecheck, Biome четырёх TS-файлов и diff-check прошли.

Независимое итоговое ревью `ad7a1b06` — CLEAR: все прежние замечания закрыты,
26 дополнительных контрпримеров и допустимых примеров прошли. Runtime компонентов
не менялся. Повторные проверки того же native runtime не требуются этим изменением.
