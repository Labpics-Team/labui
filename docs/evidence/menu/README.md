# Menu family — установленный потребитель

`packed.json` фиксирует SHA256 установленных npm-архивов, результаты двух
headless-браузеров и время до полезного обновления. Сценарий:
`pnpm --filter @labpics/ui-docs test:menu-packed` после сборки пакетов.
До публикации Icons можно передать точный архив через `LAB_ICONS_TARBALL`.

Проверены публичные ESM-типы, SSR-гидратация Vue/Solid/Svelte/Astro, живой Vue,
20 React StrictMode remount, однократная команда и отсутствие ошибок после
размонтирования. Для каждой темы сохраняются Dropdown, Context Menu и Menubar.
Dropdown — 256×386; Menubar — общий левый край и внешний gap4; все панели имеют
четыре слоя авторской тени. Source Dropdown использует Filled component; остальные
source-иконки — Outline. Исходники Figma перечислены в [справке](../../reference/menu-family.md).

Windows Chromium подтверждает видимое исполнение source-композиций. Windows
WebKit подтверждает поведение, текст, геометрию и жизненный цикл. Его headless
capture-blend возвращает серый backdrop и не подтверждает оптическую точность
материала; такое же ограничение воспроизводится на контрольной общей поверхности.
PNG сохранены без подмены. Визуальная квалификация WebKit требует реального
macOS display; эти артефакты её не заменяют.

Регрессии производительности проверяются отдельно:

- После 1000 обновлений Menu, Tooltip и Select данные остаются живыми. Vanilla
  1.48 хранит первоначальный getter и обновляет watchers без накопления getter-цепочки.
  До исправления Menu1000 занимало 368968мс, после — менее секунды.
- При одинаковых 50 видимых строках сравниваются 0, 50 и 500 скрытых дочерних
  команд. Уведомления машин объединяются в одну отрисовку. Независимый замер
  Chromium уменьшил открытие 50×10 с 341,4 до 33,6мс; полный сохранённый прогон
  с ожиданием двух кадров приведён в `packed.json`.

36 сценариев `menu.spec.ts` дополнительно проверяют управление состоянием,
disabled parent, две вложенности, переключение Menubar из вложенной команды,
RTL, возврат фокуса, перестановку строк и локальный popover внутри modal dialog.
После обновления vanilla также прошли 25 Tooltip-сценариев; один CDP-only сценарий
штатно пропускается в WebKit. [Native-проверки](../../../native/compose/evidence/menu-20261120/README.md)
включают установленный Maven consumer, обе темы и 100/200% масштаб шрифта.
