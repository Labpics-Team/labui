# Настройки рабочего пространства

Рабочий веб-сценарий объединяет Card, Button, Input, Switch и новый React Sheet.
Название и уведомления сохраняются локально; отмена восстанавливает принятые
значения. Colors Program меняет тему и контраст. Исходная Figma не менялась.

Production build прошёл шесть проверок Chrome/WebKit: пустое имя, Unicode,
отмена, сохранение и reload, возврат фокуса, клавиатура, смена темы,
положение панели и reduced motion. Axe не обнаружила нарушений в проверенной
мобильной сцене. Core/React/Docs typecheck и проверка форматирования прошли.

Рендер: `node tests/experience-render.mjs http://127.0.0.1:4328` из `apps/docs`
после сборки и запуска preview. Восемь PNG показывают обе темы на desktop/mobile,
обычную страницу и открытую панель; версия браузера находится в `render.json`.

Граница текущего среза: Lit Sheet, Snackbar и подключение нового Icons consumer
ещё продолжаются. Перемещение поверхности уже сохраняет подготовленные эффекты,
но нижний край Glass при постоянной высоте показал отличие от ограниченной
поверхности. Следующая реализация должна сохранить эту границу и исключить
покадровую генерацию поля; полнота материалов этим срезом не принята.
