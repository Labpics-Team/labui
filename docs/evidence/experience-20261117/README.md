# Настройки рабочего пространства

Рабочий веб-сценарий объединяет Card, Button, Input, Switch и Sheet.
Название и уведомления сохраняются локально; отмена восстанавливает принятые
значения. Colors Program меняет тему и контраст. Исходная Figma не менялась.

## Sheet: Lit и React

Оба исполнения используют один CSS, измерение геометрии и Lab Motion. Lit
использует нативный dialog/top layer, сохраняет DOM, слоты и тему. Публичный
порт Button `interactionTarget` связывает настоящий control с панелью.
Немодальная панель сохраняет фокус внешнего ввода, повторное открытие во время
exit работает; закрытие родителя завершает модальность вложенного Sheet.

Headless Chrome/WebKit: 12 проверок Lit проходят на dev-сборке; на production
проходят все 18 проверок Lit Sheet и React-сценария. Отдельно
проверены слоты, ввод, пять положений, reconnect, outside/Escape/native close,
scroll lock, быстрый reopen и вложенное закрытие. Core/React/Docs typecheck,
Biome и git diff --check прошли. Независимое ревью нашло три ошибки
фокуса/жизненного цикла; исправления закреплены этими регрессиями.

Нижний край Glass сохранён настоящей ограниченной высотой. Измерения и
оставшиеся редкие drag pauses описаны в
[проверке материалов](../materials-20261117/sheet-performance.md).

Рендер: `node tests/experience-render.mjs http://127.0.0.1:4328` из `apps/docs`
после сборки и запуска preview. Снимки — технические доказательства состояния
реализации, не принятие эстетического качества приложения.

## Оставшаяся работа первого сценария

Input требует авторской рамки с подписью в разрыве и общих размеров;
Snackbar и новый Icons consumer ещё продолжаются. Композиция и тексты
демонстрации требуют доводки после прямой критики пользователя. Этот срез
не означает готовности полного каталога или выпуска.
