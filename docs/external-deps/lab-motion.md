# External dependency — `@labpics/motion` (шов словаря движения)

> Реестр шва между LabUI и headless-движком анимаций `Labpics-Team/lab-motion`.
> LabUI **не** реализует физику движения (пружинный солвер, компилятор
> `linear()`-планов, WAAPI-handoff) — это территория движка. Здесь фиксируется,
> что именно пересекается, кто эталон и как не разъехаться.

## Статус: словарь СВЕДЁН (2026-07-09)

Такт оркестратора закрыл расхождение, объявленное в
[`docs/motion-tokens.md`](../motion-tokens.md): lab-motion PR #86 привёл
физический словарь движкового субпутя `@labpics/motion/tokens` к байт-в-байт
зеркалу ДС-схемы (`--lab-motion-*`).

| Пересечение | SSOT (этот репо) | Движок (lab-motion) | Статус |
| --- | --- | --- | --- |
| Длительности `instant/fast/base/slow/slower` | `src/motion/config.ts`: 0/100/200/300/500 мс | `src/tokens`: `duration.*` — те же значения и имена | **Сведено** |
| Изинги `standard/decelerate/accelerate/emphasized` | официальные кривые M3; `emphasized` — единственный overshoot (y1=1.21) | `src/tokens`: `easing.*` — те же координаты (`fn` + `css` из одного источника) | **Сведено** |
| Пружины `smooth/expressive` | каноническая пара (duration, bounce): (0.35, 0) и (0.5, 0.3) | `spring.smooth/expressive` выведены через `springFromDurationBounce` | **Сведено** |
| Формулы пары → физтройка | `src/motion/spring.ts`: ζ=1−bounce, m=1, ω₀=2π/T, k=ω₀², c=2ζω₀ | `springFromDurationBounce` — те же формулы, запинены тестом «формулы SSOT» | **Сведено** |

Движковые экстры — пресеты `spring.default/gentle/snappy/bounce`, `staggerGap`,
`distanceScale` — честное надмножество: таких имён в ДС-схеме нет, конфликт
исключён пинами с обеих сторон.

## Дисциплина шва

- **Эталон — LabUI.** Любой будущий сдвиг значения/имени в
  `packages/tokens/src/motion/` требует зеркального PR в lab-motion
  (`src/tokens/index.ts` + пины `test/tokens.test.ts`); движок сам значения не
  двигает.
- **Замки.** С обеих сторон значения запинены value-пинами: здесь — schema-тесты
  генератора и контракт-гейт `motion.css`; в движке — `test/tokens.test.ts`
  (пины значений/имён, тест формул канонической пары, api-surface-pin). Тихий
  дрейф с любой стороны красный.
- **Разные представления — одна физика.** LabUI эмитит статический CSS-контракт
  (`--lab-motion-*`, `linear()` сгенерирован при сборке); движок несёт те же
  значения в рантайм-форме (`fn`+`css`, `SpringParams`). Пересчёт пары в тройку
  обязан давать идентичные числа — обе реализации детерминированы и
  бездиффузны (никаких округлений сверх IEEE-754).

## Что LabUI потребляет сегодня

Ничего в рантайме. Компоненты едят **только** CSS-контракт `--lab-motion-*` из
`@labpics/ui-tokens` (motion.css); генератор схемы самодостаточен. Движок нужен
потребителям, которым мало декларативного CSS: интерактив/жесты
(follow-фаза), FLIP, каскады, compositor-handoff.

## Открытые хвосты (владельцу)

- `@labpics/motion@0.1.0` **опубликован в npm** (2026-07-09 06:55 UTC), но —
  ДО сведения словаря (lab-motion PR #86 смержен позже тем же днём): в 0.1.0
  ещё старая шкала (150/250/400/600, `normal`, `entrance`/`exit`) и нет
  `springFromDurationBounce`. Кросс-репо тест байт-паритета словаря (импорт
  обоих пакетов в одном тесте) ждёт **релиза ≥0.2.0** с уже сведённым
  словарём; до тех пор паритет держат парные value-пины по обе стороны шва.
  README движка про «не опубликован» устарел — правится на стороне lab-motion.
