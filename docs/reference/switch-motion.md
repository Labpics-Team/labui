# Движение Switch

Lit и React Switch используют один контроллер `ui-core/motion` и опубликованный
LabMotion 0.5.0. Состояние, ARIA и форма обновляются через Zag сразу. Пружина
перемещает только бегунок; геометрия компонента сохранена. Цвет и прозрачность
иконок меняются сразу: промежуточные цветовые пары ещё не прошли проверку
контрастности Color assignment. Их интерполяция требует отдельной квалификации.
Потребитель загружает `@labpics/ui-tokens/motion.css` вместе с `tokens.css`.

## Характер

Роль `toggle` принадлежит LabUI. В `packages/tokens/src/motion/config.ts` заданы
`response: 320` миллисекунд и `bounce: 0.22`. Это калибровка короткого хода 12–20 px:
заметный отклик, деликатный перелёт и быстрое успокоение. Response описывает
пружину и не обещает окончание всей анимации через 320 ms. Завершение определяет
LabMotion по своему критерию покоя.

Генератор выпускает CSS, DTCG и статическую runtime-проекцию одной роли.
LabMotion преобразует response/bounce в физические параметры, вычисляет
траекторию и сохраняет скорость при новой цели. В LabUI нет второго solver
или кадрового планировщика. Новая калибровка меняет config и его проекции;
рендеры не знают её значений.

## Настройки и жизненный цикл

Существующий CSS `--lab-motion-transition-duration` сохраняет действие как
относительный масштаб времени. Базовые 100 ms дают выбранный характер;
200 ms замедляют его вдвое, 50 ms ускоряют вдвое. Это сохраняет настройку
скорости, но не делает длительность затухания равной CSS duration. Контроллер
читает вычисленную длительность перехода transform при новой цели. Значение
0 или `transition: none` отключает движение. Геометрия использует роль пружины;
CSS easing не заменяет её.

`prefers-reduced-motion: reduce` всегда переводит бегунок в текущую конечную
позу, включая изменение системной настройки во время движения. Изменение
CSS-настройки скорости применяется со следующей целью. Размеры вычисляются
в локальных CSS-координатах: масштабирование предка не увеличивает ход второй
раз. ResizeObserver обновляет цель при изменении размера Switch или rem.

В Lit начальное состояние дорожки, бегунка, иконок и input видно до JavaScript:
SSR-разметка содержит стили и единую проекцию effective checked. Явный false
имеет приоритет над defaultChecked и сохраняется при hydration. React SSR
передаёт checked-состояние в разметку, но компонентные стили подключаются через
JavaScript; визуальная готовность React до его выполнения пока не обеспечена.
При подключении контроллер фиксирует начальную позу без анимации.

При отключении scope снимает движения и подписки,
а контроллер восстанавливает принадлежащие ему inline-свойства. Новые inline
transition-property и их приоритет, записанные потребителем после подключения,
учитываются при следующей цели и сохраняются при cleanup, включая `none !important`.
Служебная запись контроллера использует частное имя свойства в списке CSS
transition-property; она исключает transform и отличима от настройки `none`.
Lit reconnect
и повторное подключение React создают новую область. Прямое редактирование
inline transform бегунка во время работы не является публичной настройкой.

## Основания и граница проверки

Выбран штатный scalar retarget API LabMotion 0.5.0:
[опубликованный пакет](https://registry.npmjs.org/@labpics/motion/0.5.0),
[исходник версии](https://github.com/Labpics-Team/lab-motion/tree/68825562824353bca377e00a3107895796229ff4).
CSS transitions при смене направления не переносят скорость пружины.
[Apple](https://developer.apple.com/videos/play/wwdc2023/10158/) и
[Compose Animatable](https://developer.android.com/reference/kotlin/androidx/compose/animation/core/Animatable)
использованы как источники механики непрерывного движения, а не стиля LabUI.

Browser suite `apps/docs/tests/switch-motion.spec.ts` проверяет реальные
компоненты, смену направления, размеры, SSR, уменьшение движения и отключение.
Это первый runtime-срез движения Switch; остальные компоненты и нативные
адаптеры требуют своих потребительских проверок.
