# ColorPicker для Compose

`LabColorPicker` переносит 15 сочетаний авторского ColorPicker: Grid, Spectrum и
Sliders × HEX, HSB, HSL, RGB и LCH. Геометрия, типографика, роли цвета и 100 цветов
палитры приходят из общего `components.json#colorPicker` через `LabComponents`.
Компонент использует Foundation, Lab Menu, SegmentedControl, Switch и Elevated.

```kotlin
val color = rememberLabColorPickerState(
    LabColorValue(LabColorSpace.Lch, 72.09123456789, 84.86123456789, 65.34123456789),
)
LabColorPicker(
    state = color,
    label = "Colors",
    onValueChangeEnd = { accepted -> /* завершённое изменение */ },
)
```

## Принятое значение и форма

`LabColorValue` хранит три конечные координаты и alpha как `Double`; alpha лежит
в диапазоне 0…1. Входной список копируется, возвращаемый `coords` не открывает
изменяемое внутреннее состояние. LCH означает CSS CIELCH с белой точкой D50.
HSB интерфейса соответствует `LabColorSpace.Hsv`; sRGB хранит каналы в долях 0…1,
HSL/HSV — hue в градусах и остальные каналы в процентах.

Controlled-перегрузка принимает `value` и `onValueChange`. Callback запрашивает
изменение; принятое значение задаёт приложение. `onValueChangeEnd` получает
фактически принятое значение после рекомпозиции и не вызывается при отказе или
возврате к исходному значению. Переключение модели, вида и охватов, рисование и
копирование не заменяют исходные координаты производным представлением.

`LabColorPickerState` добавляет `reset()`, `formValue()` и `isMissing(required,
enabled, readOnly)`. Reset восстанавливает точное начальное значение, очищает
черновик и отменяет активный жест/выбор с экрана без change/end. Значение `null`
обозначает пустую форму. `rememberLabColorPickerState` сохраняет текущие и начальные
Double-координаты через Compose `rememberSaveable`; оно не является дисковым
хранилищем приложения. `formValue()` выдаёт структурированный JSON без округления:

```json
{"space":"lch","coords":[72.09123456789,84.86123456789,65.34123456789],"alpha":1.0}
```

## Ввод и доступность

Текстовые поля используют Foundation `TextFieldState`. Enter, IME Done и потеря
фокуса принимают изменённый текст; Escape восстанавливает принятое представление.
Фокус/blur без редактирования не записывает округлённый показанный текст обратно.
IME composition и завершающий её Enter не отправляют незавершённый ввод.
После отказа controlled-потребителя поле показывает принятое значение.

Плоскости доступны указателем, стрелками и отдельными accessibility actions для
двух осей. Полосы поддерживают стрелки, Page Up/Down, Home/End и SetProgress.
Escape во время жеста возвращает точный снимок начала жеста. Read-only запрещает
цветовые изменения, сохраняя возможность изучать представления и копировать.
Disabled исключает изменение и отменяет ожидающий внешний выбор цвета.

## Цветовой codec и графики

Преобразования выполняет `colormath:3.7.1`; его Float-результаты используются
только для проекций и рисования. Никаких повторных Float→Double преобразований
принятого значения при просмотре нет. Локальная граница codec настраивает
публичные API библиотеки под CSS: Bradford для D50↔D65, gamma 2.4 BT.1886 для
Rec.2020 и симметричное расширение sRGB/Display P3 для отрицательных каналов.
Отрицательная производная HSL saturation приводится к CSS-представлению:
поворот hue на 180° и положительная saturation. Для известного shortcut
`colormath` при L=0/C≠0 только проекция использует `Float.MIN_VALUE` вместо нуля:
добавленная яркость исчезает при Float-округлении, а библиотека сохраняет Chroma.
Исходный L=0 не меняется; этот случай отдельно входит в независимый oracle.

LCH-графики явно задают оси. Spectrum содержит L×C и H×C; в Sliders строки
Lightness, Chroma и Hue содержат L×C, H×C и H×L. Изменение alpha и движение
маркера в неизменной плоскости не пересчитывают растровое изображение.
Диапазон Chroma — 0…145, при показе Rec.2020 — 0…195; одна величина управляет
графиком, маркером, шкалой и преобразованием позиции указателя.
Компонент хранит до девяти изображений, ограниченных 342×342 пикселями. Растер
строится на `Dispatchers.Default`, отменяется между строками и повторно использует
библиотечные RGB-конвертеры. Плоскости показывают реальные сечения охвата;
показ P3/Rec.2020 расширяет видимую область, но не переписывает цвет.

## Выбор с экрана и clipboard

`pickScreenColor: LabPickScreenColor?` — необязательная suspend-функция настоящего
выбора пикселя экрана. Без неё eyedropper недоступен. Пакет не поставляет OS sampler
и не подменяет его обычным цветовым диалогом. Приложение подключает поддержанный
платформой контракт; `null` означает отмену. Полученные координаты сохраняют
последний принятый alpha. Detach, reset, disable и read-only отменяют ожидание;
поздний результат отменённой операции не применяется. Ошибка показывает сообщение
и позволяет повторить действие. Copy использует настоящий Compose clipboard.

## Проверки и граница подтверждения

[Native evidence](../evidence/color-picker-20261123/native/README.md) содержит
все 15 offscreen PNG, узкую тёмную панель при 125%, численные ошибки и JUnit XML.
Проверки проходят через `ImageComposeScene` с `SKIKO_RENDER_API=SOFTWARE`, без
окон, звука и стороннего screen reader. Numeric oracle — 2304 независимых вектора
Color.js 0.7.1, включая D50, цвета вне sRGB, L=0/100 и C=195.
Бюджет ошибки RGB — 0.00002, обычных HSL/HSV/LCH — 0.005
в единицах соответствующего канала. За пределами охвата HSL saturation может
превышать 10000% и плохо обусловлена около L=0/1: для неё проверяется ошибка
обратной RGB-проекции ≤0.00002. Это проверка выбранных
векторов, а не доказательство границы на всех конечных Double.

Desktop compile, offscreen-взаимодействие и common Kotlin metadata проверены.
Android compile требует отсутствующий на этой машине SDK; Android/iOS runtime,
системный screen reader и реальный OS screen sampler этой проверкой не заявлены.
