# Типографика

Авторский текстовый стиль задаётся целиком: семейство, кегль, интерлиньяж,
насыщенность и трекинг. Один кегль не определяет стиль. Например, у Geist
Regular 16/24 трекинг −0.25 px, а у Medium 16/24 — 0.

Источник точных ролей — [`text-styles.json`](../../packages/tokens/src/text-styles.json).
Каждая роль хранит идентификаторы текстового узла и стиля исходной Figma.
Сохранённые значения REST находятся в [свидетельстве проверки](../evidence/typography-20261119/README.md).

| Роль | Стиль Figma | Кегль / интерлиньяж | Вес | Трекинг |
| --- | --- | --- | --- | --- |
| `body` | Text/M-Common | 16 / 24 px | 400 | −0.25 px |
| `body-emphasized` | Text/M-Emphasized | 16 / 24 px | 500 | 0 |
| `headline` | Headline/L-Common | 20 / 20 px | 500 | −0.33 px |
| `caption-xs` | Caption/XS | 12 / 12 px | 500 | 0 |

Это подтверждённые общие роли, а не полный перечень стилей Figma.
Специальная типографика компонента остаётся в его профиле, пока её связь
с общей ролью не установлена. Например, Card Caption 14/12 не заменяется
на `caption-xs`, а Sheet Title сохраняет свой вес 600.

## Проекции и потребители

Web получает `--lab-font-size-<role>`, `--lab-line-height-<role>`,
`--lab-font-weight-<role>` и `--lab-letter-spacing-<role>` в `tokens.css`.
Размеры и трекинг ролей выражены в rem: увеличение корневого размера шрифта
сохраняет их пропорции. Для применения полного стиля есть типизированный объект:

```ts
import { textStyle, type TextStyleRole } from '@labpics/ui-tokens';

const role: TextStyleRole = 'body';
const style = textStyle[role];
// Например, <p style={style}> в React.
```

Семейство следует общей `--lab-font-family`; штатная поставка — Geist.
DTCG хранит роли как составные токены `typography` с точными px-значениями,
числовым весом и относительным интерлиньяжем. Native-генератор читает эти же
токены и создаёт целые `TextStyle`, переводя размеры в sp. `LabTheme` добавляет
выбранное семейство и цвет. Внутренние `LabType.body/emphasized/title/caption`
выбирают авторскую роль целиком.

В исходном `components.json` ссылка `"$textStyle": "body"` заменяет четыре
числовых текстовых поля. Общий `resolve-text-styles.mjs` используется web- и
native-генераторами. Неизвестная роль или попытка переопределить её отдельную
метрику завершают сборку ошибкой. Card Title/Description, Sheet Description
и Choicebox label получают метрики через такие ссылки. Choicebox description
использует общую `body` напрямую на обеих платформах.

Экспортируемый `@labpics/ui-tokens/components.json` содержит развёрнутые
числовые поля прежней формы: потребителю не нужен обработчик ссылок.

## Плавная шкала

Существующие `fontSize`, `lineHeight`, `letterSpacing` и соответствующие
`--lab-*-md/xl/…` сохраняют прежний API и значения. Это настраиваемая плавная
шкала для композиции приложения. Её эвристики трекинга и интерлиньяжа
не воспроизводят авторские роли. Настройка `basePx` или модульных отношений
изменяет эту шкалу; точные роли компонентов от неё не зависят.

У fluid-токена нет единственного кегля. Его DTCG-скаляр сохраняет широкий якорь
ради совместимости, а `$extensions` содержит границы и формулу. Нельзя брать
этот скаляр как размер авторского заголовка в Compose.

Допуск на один межбуквенный интервал не доказывает совпадение текста:
ошибка накапливается по длине строки. Проверки сравнивают ширину целой строки
со стилем сохранённого источника и отдельно проходят реальный Choicebox.

Формат составного стиля следует
[DTCG 2025.10, Typography](https://www.designtokens.org/tr/2025.10/format/#typography).
Исходный дизайн — [Lab UI v2.1](https://www.figma.com/community/file/1527814209910933331/lab-ui-components-icons-guides-lab-ui-v2-1).
