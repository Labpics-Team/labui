# Проверки контрактов стилей

Проверки Colors читают исходный TypeScript через Compiler API, CSS через PostCSS,
селекторы и условия через CSS Tree. Они не исполняют компонентный код.

Авторский профиль из `@labpics/ui-tokens` — такой же источник размеров, как
CSS custom properties. Ограниченный разбор поддерживает константные выражения,
шаблоны, чистые локальные функции перевода единиц, `map`/`join`, `Object.entries`
и ограниченный `Array.from`. TypeScript связывает имена с декларациями через
символы: одноимённый параметр или переменная блока не получает свойств внешнего
профиля. Неизвестное выражение остаётся неизвестным.

Локальные `const` с объектом или массивом не доказывают статическое значение:
`const` не запрещает мутацию. Профиль можно читать как примитивные поля или
сразу преобразовать полностью разобранным выражением `entries`/`map`/`join`.
Запись, alias, экспорт объекта и передача его неизвестной функции снимают
доказательство для профиля; это также относится к вложенным объектам и
мутациям через callback. Проход комментариев не строит таблицу символов.

Неизвестный исполняемый initializer параметра отменяет доказательство всего
вызова, даже если тело не читает параметр. Defaults/rest внутри destructuring
остаются неподдержанными. Скобки, `as`, `satisfies` и `!` имеют одну общую границу
разворачивания для чтения, записи и проверки профильного размера.

Для размерного исключения допустимы прямое числовое поле профиля, знак и
масштабирование ненулевым числовым литералом, включая перевод единиц.
Произвольное сложение и сокращение выражения не доказывают авторскую геометрию:
`p.radius * 0 + 77` остаётся нарушением.

Системный цвет допустим, когда каждое ответвление медиаусловия требует
`forced-colors: active` и весь соответствующий блок известен. Неизвестная вставка
в другом правиле не меняет смысл завершённого блока; вставка внутрь него лишает
проверку этого основания. Литеральный брендовый цвет остаётся нарушением.

Белый и чёрный в маске описывают покрытие. Исключение распространяется только
на завершённую `mask`/`mask-image` декларацию и частный генератор, все применения
которого ведут к маске. Экспорт генератора или применение к видимому background/SVG
снимает исключение. Цветные литералы в маске не разрешены.

Числовой `z-index` дочернего слоя или `::before`/`::after` допустим внутри
подтверждённого `isolation: isolate`. Неизвестный stylesheet, потенциальный reset,
конфликт условий или приоритетов оставляет нарушение. Глобальные слои по-прежнему
потребляют шкалу `--lab-z-*`.

`--lab-material-shadow` — точное имя полного авторского стека, а
`--lab-drag-progress` — локальный числовой вход взаимодействия, не роль палитры.
Произвольные похожие имена не получают этих свойств. Радиус `50%` задаёт форму
от собственной геометрии элемента; фиксированные размеры и другие проценты
должны следовать профилю/контракту.

Проверки этих границ и контрпримеры находятся в `packages/colors/test`.
Основания: [TypeScript Compiler API](https://github.com/microsoft/TypeScript/wiki/Using-the-Compiler-API),
[CSS Color Adjustment](https://www.w3.org/TR/css-color-adjust-1/#forced-colors-mode),
[CSS Masking](https://www.w3.org/TR/css-masking-1/#MaskValues).
