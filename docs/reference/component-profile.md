# Профиль компонентов

`@labpics/ui-tokens/components.json` содержит геометрию и типографику семейств
в единицах макета. CSS/rem, TypeScript и DTCG выводятся из этого источника;
нативный генератор читает тот же профиль и переводит размеры в dp/sp.
Общие [текстовые роли](typography.md) заданы в `text-styles.json`;
исходный профиль ссылается на них через `$textStyle`. Оба генератора
разворачивают ссылки одним обработчиком; экспорт пакета сохраняет числовой JSON.
Профиль семейства не расширяет глобальные шкалы размеров.
`sourceRef.key` разрешается через [реестр каталога](../../catalog/registry.json);
происхождение не копируется в профиль и не превращается в runtime-константы.
Точные selectors и пути измеряемых слоёв описаны в [справке каталога](catalog.md).

## Button

Источник — [Lab UI v2.1](https://www.figma.com/community/file/1527814209910933331/lab-ui-components-icons-guides-lab-ui-v2-1),
страница Button, семейство Button, размеры S/M/L. Публичные ссылки используют
семантические имена; идентификаторы приватного файла остаются в локальном источнике.
Размеры s/m/l: 36/48/56, радиусы pill/16/16. Анатомия:
ведущая иконка → Main и Description → завершающая иконка.
Внутри label — отступы 8 и промежуток 8; внешний промежуток отсутствует.

Main использует Geist 500. Description: 500 для s, 400 с tracking −0.25
для m/l. Альфа Description — .72; у accent border/ghost m/l макет задаёт
полный цвет. Fill сохраняет заливку действия, градиентный блик .20 и
внутреннюю тень (0, −1, blur 1); hover меняет блик до .32, press — до
затемнения .12. Цвет внутреннего края задаёт роль `--lab-fx-control-inner`.

Lit предоставляет `icon`, default, `description`, `icon-end` slots;
React — `iconSlot`, `children`, `description`, `iconEnd`. Loading сохраняет
ширину и доступное имя, скрывая декоративные иконки. Main заменяется
восьмисегментным индикатором размера иконки; Description остаётся видимым.
Hover border/ghost показывает тонированную поверхность, pressed снимает её.
Disabled сохраняет border/ghost прозрачными и ослабляет рамку.
Для icon-only нужен
`aria-label`; он присутствует на внутренней кнопке и в SSR.

Проверка: `apps/docs/tests/button.spec.ts` выполняет реальные Chromium/WebKit
сравнения размеров, типографики и состояний в обеих темах и при масштабе 200%.
`packages/core/test/ssr-slot-detection.test.ts` проверяет декларативный Shadow DOM.
