# Поля ввода: расширения

Combobox, Number Input и Tags Input — композиции существующего Lab UI. Отдельного Figma master для них нет. Все три используют прозрачную рамку, вырез под подпись, три размера и состояния Input. Combobox переиспользует Dropdown, метки — Chip. Изменение исходного профиля действует на композиции автоматически.

## Значение и форма

В web-компонентах `value = null` означает локальное состояние от `defaultValue`. Переданный `value` — принятое значение: событие `value-change` только запрашивает изменение. Присваивание JS-свойства и HTML-атрибут равноправны. В React отсутствие `value` выбирает локальное состояние. Отменённый `reset` сохраняет значение; обычный сброс возвращает исходный `defaultValue`. Disabled fieldset и отдельный disabled исключают поле из отправки.

Combobox отправляет выбранные ключи, Tags Input — метки: по одной записи `name` на значение. Текст поиска или незавершённая метка не отправляются. Number Input отправляет текстовое числовое значение. `required` проверяет принятые значения, а сообщение ошибки связано с доступным редактируемым контролом.

## Взаимодействие

- Combobox: ввод фильтрует по подписи, стрелки перемещают активный вариант, Enter выбирает, Escape закрывает. Недоступные варианты пропускаются. Локальный manual popover сохраняет тему и контекст формы, одновременно выходя в верхний слой браузера. Фокус остаётся в input.
- Number Input: стрелки и кнопки изменяют число на `step`; Page Up/Down дают крупный шаг. Промежуточный текст сохраняется во время ввода; при фиксации применяется min/max. Колесо изменяет значение только при `allowMouseWheel`.
- Tags Input: Enter добавляет, стрелки перемещают выделение, Backspace/Delete удаляют. Редактирование метки завершается Enter и отменяется Escape. Вставка списка включается `addOnPaste`; `max` и `allowDuplicates` определяют допустимый результат. Завершение IME не выполняет действие Enter.

Размеры заданы относительными единицами; длинные метки переносятся. Подпись остаётся связанной с полем при 200% масштабе. Общий ZagController хранит одно завершение подписки на текущий DOM-узел, освобождает удалённые узлы после рендера и все ресурсы при disconnect.
