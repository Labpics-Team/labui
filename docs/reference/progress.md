# Loader и Progress

`value` — измеренное значение, `null` — неизвестная доля. Оба компонента принимают
`min`/`max` (0/100 по умолчанию). Конечное значение ограничивается диапазоном;
нечисло, бесконечность и невозрастающие границы дают неизвестное состояние.
Процент вычисляется после нормализации; округление относится только к подписи.
Нулевое значение остаётся известным. Значение не растёт само с течением времени.

Loader использует четыре авторских мастера: неизвестный восьмисегментный знак
и известную долю в размерах m=24 и l=48. Численный m сохраняет внешнее кольцо
и внутренний сектор, l — дугу на приглушённом кольце. Размер s=16 — расширение
с рисунком medium. Нейтральный цвет задан `label-primary`; цвет Loader можно
переопределить через обычный `color`.

Progress `variant='linear'|'circular'` меняет представление, сохраняя значение.
Linear m имеет толщину 4 px, Circular m — диаметр 96 px и обводку 4 px с круглыми
окончаниями. `showValueText` независимо включает подпись: в Figma это ось
Circular «Determinate», хотя обе её строки содержат доли 0–100%.
Надпись скрывается при неизвестном значении. Дополнительные s/l:
Linear 2/8 px, Circular 64/128 px, обводка 4 px. Размеры масштабируются с текстом
в вебе; Compose сохраняет dp-геометрию и увеличивает место для системного текста.

Изолированный процент Circular центрируется по cap-height и базовой линии
через `text-box: trim-both cap alphabetic`. Вложенный span отделяет эти метрики
от контейнера, который центрирует текст. Это правило не меняет многострочные
label и не вводит поправки в пикселях; без поддержки text-box остаётся обычное
центрирование line box. Источник: [CSS text-box](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-box).

Каждое представление — один именованный `progressbar`. Численное значение
передаётся через `aria-valuenow`; неизвестное его не имеет. Label называет работу,
а не её процент. В Compose действует эквивалентная ProgressBarRangeInfo.
Отображение не требует запуска клиентской машины: SSR содержит рисунок,
значение и семантику, а reflected attributes сохраняют их после гидрации.

Lab Motion отвечает только за изменение рисунка: реальное число и доступная
подпись меняются сразу, доля плавно достигает нового значения. Неизвестное
состояние использует шаги спиц или бегущую дугу/полосу. Reduced motion сохраняет
статичный знак без ложного процента; невидимый документ прекращает циклы.

Профили в `packages/tokens/src/components.json#loader` и `#progress` — общий
источник геометрии, цветовых ролей и круговых окончаний Lit/React/Compose.
Цвет track уже содержит авторскую alpha 0.32; повторная opacity не применяется.
Угловой gradient medium Loader приведён к эквивалентному clockwise-виду:
secondary при 0°, primary при 270°, secondary при 360°; маска задаёт реальную долю.
