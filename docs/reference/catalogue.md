В [catalogue.json](catalogue.json) сохранены 80 наборов, 1682 варианта внутри них
и 14 самостоятельных компонентов. Наборы включают внутренние элементы вроде
ячейки ввода или пункта меню; это не число публичных API библиотеки.

в коде не подтверждает его анатомию, поведение или визуальное соответствие.

## Как читать снимок

`variantNames` — фактические имена дочерних компонентов. Они сохранены без
вывода всех возможных комбинаций свойств. `axes` и `tuples`, где они есть,
получены отдельно из `variantProperties`; порядок значений задаётся `axes`.
Поле `evidence` различает эти два уровня чтения. Имена вариантов сами по себе
не удостоверяют значения свойств.

У Button сохранены все 432 фактических сочетания по пяти осям:
`Type`, `Kind`, `Icon-button`, `Size`, `State`. Значения Type — accent, neutral,
danger; Kind — fill, tinted, border, ghost. Состояния — default, hover, pressed,
loading, disabled, focus. Связь этих свойств с режимами, материалами и
семантическими ролями LabColors проверяется отдельно.

Bottom Sheet содержит пять состояний: Full, 2/3, Half, 1/3 и Flex.
Его декларация включает опциональные Header, Description, Controls,
Primary button, Secondary button и Title, текстовые Title/Description,
заменяемый Body и слот Content area. Header и Controls по умолчанию скрыты;
остальные перечисленные boolean-свойства включены. Это свойства исходной
анатомии; окончательный API кода требует проверки поведения вложенных областей.

## Что остаётся сверить

Полный набор property definitions, наследуемые режимы, отношения материалов,
показ скрытых областей и визуальное поведение прочитаны не для каждого набора.
Структурное чтение всех страниц не означает визуальной приёмки всех вариантов.

Соответствие эталона веб- и нативным компонентам проверяется отдельно.
Текущий код для последующего сопоставления закреплён на
`f47e2bab11510f82781477176939cf54ac573b70`; этот снимок не назначает статус
готовности компонентам. В частности, общий dialog не удостоверяет Bottom Sheet,
а tabs не удостоверяет Segmented Control.

Разбор геометрии, эффектов и уже просмотренных состояний находится в
[эталоне реализации](design-baseline.md).
