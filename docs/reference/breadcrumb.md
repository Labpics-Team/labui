# Breadcrumb

Навигационная цепочка показывает положение страницы в иерархии. Предыдущие
страницы — обычные ссылки, последняя — текст с `aria-current="page"`.
Группирующий раздел без адреса остаётся текстом. Разделители декоративны.
Необязательный `id` сохраняет идентичность пункта при переименовании и смене
адреса. Без него web использует адрес или подпись, Compose — подпись.
Для повторяющихся адресов/названий в изменяемом пути задавайте уникальные `id`.
Вставка или удаление другого предка сохраняет сфокусированный пункт.

```tsx
<Breadcrumb items={[
  { label: 'Пространства', href: '/workspaces' },
  { label: 'Дизайн', href: '/workspaces/design' },
  { label: 'Настройки' },
]} />
```

В Lit массив передаётся свойству `items`; отражённый JSON-атрибут переносит
тот же путь через SSR и hydration, включая Astro без клиентской передачи props.
React использует `maxItems`, Lit —
`max-items`: максимум видимых позиций, включая многоточие; по умолчанию 4.
Ноль показывает весь путь. У длинного пути сохраняются корень и последние
уровни; многоточие раскрывает середину в исходном порядке и переносит фокус
к первому раскрытому пункту. Это не меню и не история переходов пользователя.

`label` задаёт имя навигационной области, `expandLabel` (`expand-label`) —
кнопки раскрытия. React также принимает стандартный `aria-label`.
По умолчанию используются «Навигационная цепочка» и «Показать все разделы».
`separator` позволяет передать собственный разделитель; исходный шеврон
автоматически разворачивается в RTL. Подписи сохраняются при переносе строк.

```kotlin
LabBreadcrumb(listOf(
    LabBreadcrumbItem("Пространства") { navigateToWorkspaces() },
    LabBreadcrumbItem("Дизайн") { navigateToDesign() },
    LabBreadcrumbItem("Настройки"),
))
```

Compose принимает действия приложения, не зависит от маршрутизатора и
не исполняет действие последнего пункта. При раскрытии фокус переходит к
первому раскрытому пункту с действием. Размер текста, интервалы и знаки
следуют системному fontScale один раз; DPR применяется renderer.

Размер M воспроизводит [Lab UI v2.1](https://www.figma.com/community/file/1527814209910933331/lab-ui-components-icons-guides-lab-ui-v2-1):
Geist Medium 14/12, нулевой tracking, шаг 8, знаки 16. S и L — расширения
профиля, не дополнительные варианты Figma. Текущий пункт сохраняет Medium;
он отличается основной ролью цвета. Межстрочный интервал длинных подписей
увеличен, внешнее leading снято: одна строка сохраняет авторскую геометрию.

Единый источник геометрии — `packages/tokens/src/components.json#breadcrumb`.
Контуры шеврона и многоточия прочитаны из исходных слоёв компонента; CSS mask
и подготовленные Compose Path получаются из одного профиля. При отрисовке
нет SVG parsing, измерительных observers или кадровых вычислений.

Семантика следует [WAI-ARIA Breadcrumb Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/).
Web CSS для SSR без JS доступен как `@labpics/ui-core/breadcrumb.css`.
