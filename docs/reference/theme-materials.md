# Темы и материалы

Справочник описывает публичный контракт текущего веб-workspace.
Ось темы и ось материала задаются на корне приложения или вложенной области.

## Оси

| Ось | Атрибут | Значения | Публичный тип |
| --- | --- | --- | --- |
| Тема | `data-theme` | `light`, `dark` | `Theme` из `@labpics/ui-core` |
| Материал | `data-material` | `solid`, `glass`, `acrylic` | `Material` из `@labpics/ui-core` |

`setTheme(root, theme)` и `setMaterial(root, material)` устанавливают
соответствующий атрибут. Значения и типы определены в
[theme.ts](../../packages/core/src/theme.ts).
Компонент получает итоговые семантические CSS-переменные через каскад.

При отсутствии явно заданной темы CSS учитывает `prefers-color-scheme`,
затем светлую тему. Solid — материал по умолчанию.
Политика вложенности поверхностей определена в
[background-policy.ts](../../packages/materials/src/background-policy.ts).

## Публичные входы

| Вход | Назначение |
| --- | --- |
| `@labui/colors/contract.css` | Семантические цветовые роли Lab UI |
| `@labpics/ui-tokens/tokens.css` | Размеры, отступы, радиусы и типографика |
| `@labpics/ui-core/theme.css` | Стили и соглашение о выборе темы |
| `@labpics/ui-materials/material.css` | Стили материалов и поверхностей |
| `@labpics/ui-materials` → `mountMaterialRuntime` | Подключение браузерных эффектов материалов |

## Runtime и поддержка эффектов

`mountMaterialRuntime(root?: Document | Element): () => void` подключает
движки к переданной области; без аргумента используется документ.
Возвращённая функция освобождает принадлежащие этому подключению ресурсы.
Монтирование выполняется в браузере после создания DOM.

Runtime обслуживает `lab-material` в областях Glass/Acrylic и элементы
с `data-veil`. Progressive blur имеет собственный атрибут и проверку поддержки;
он не добавляет четвёртое значение оси материалов.

Исполнение зависит от поддержки браузером фильтров и системных настроек.
Текущий runtime использует усиленные Glass/Acrylic-движки при поддержке
их цепочки фильтров; в остальных случаях остаётся CSS-реализация.
Условия подключения определены в
[runtime.ts](../../packages/materials/src/engine/runtime.ts)
и [движках Materials](../../packages/materials/src/engine/).
Переход к Solid не подтверждает отрисовку Acrylic или Glass.

## Платформенное требование

Solid и Acrylic должны иметь настоящие реализации на каждой платформе
согласованной матрицы Lab UI. Это требование системы; готовность отдельного
нативного SDK подтверждается его собственным рендером и потребителем.
Текущие веб-пакеты не служат доказательством готовности нативных SDK.

В эталоне название Blur сопоставляется с Acrylic по составу слоёв и рендеру.
Прочие свойства компонента сохраняются при смене материала:
[инвариант компонента и материала](invariants.md#компонент-и-материал).
