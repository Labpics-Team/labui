# Kbd

Kbd показывает физическую клавишу или сочетание. Компонент не выполняет действие,
не получает фокус и не добавляет роль кнопки. Web использует настоящий `<kbd>`;
у сочетания каждая клавиша вложена в общий `<kbd>`.

```tsx
<Kbd>Esc</Kbd>
<Kbd size="l" keys={['Ctrl', 'Shift', 'P']} />
```

```html
<lab-kbd>Esc</lab-kbd>
<lab-kbd size="l" keys='["Ctrl", "Shift", "P"]'></lab-kbd>
```

```kotlin
LabKbd("Esc")
LabKbd(listOf("Ctrl", "Shift", "P"), size = LabKbdSize.Large)
```

`keys` — упорядоченный список подписей. На web пустой список сохраняет прежний
default slot / `children` одной клавиши; непустой список имеет приоритет.
Vue, Svelte, Solid и Astro получают тот же список через сгенерированный API.
Подписи остаются текстом: копируются, озвучиваются и расширяют клавишу по ширине.
Для непонятного символа приложение может задать доступное название сочетания.

| Свойство | Small (`s`, по умолчанию) | Large (`l`) |
|---|---:|---:|
| Минимальная высота / ширина клавиши | 16 | 24 |
| Радиус | 4 | 6 |
| Отступ по горизонтали / вертикали | 2 / 2 | 4 / 0 |
| Geist Medium, размер / высота строки | 12 / 12 | 16 / 24 |
| Наружная нижняя грань | 1 | 2 |

Прежнее значение `m` на web — совместимое написание `l`, отдельного среднего
размера в исходной Figma нет. Web переводит размеры в `rem`; Compose использует
логические размеры и `sp` для текста. Увеличенный текст расширяет геометрию,
длинные `Esc`, `Ctrl` и `Enter` не обрезаются.

Профиль находится в `packages/tokens/src/components.json#kbd`, его источник —
`component-set/Kbd/Kbd`. Один профиль задаёт геометрию web и Compose; Lit и React
используют один CSS. Авторская матрица содержит 1–4 клавиши в двух размерах.
Список API допускает более длинные сочетания, не добавляя нового визуального типа.

Первый колпачок использует градиент `fill-tertiary → fill-none`, следующие —
`fill-quaternary → fill-none`. Подпись читает `label-secondary`, внутренняя линия
толщиной 1 — `border-base`, нижняя грань — `border-soft`. Грань является частью
геометрии, а не тенью: из внешнего контура высотой `h + depth` с радиусом `r + depth`
вычитается исходный контур высотой `h` с радиусом `r`. Контуры имеют одинаковую
ширину. На native эта разность вычисляется при изменении размера, без покадровой работы.
