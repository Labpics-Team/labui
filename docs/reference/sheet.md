# Измерение Sheet

React и Lit используют общую геометрию и runtime движения. `Flex` следует
естественной высоте содержимого, включая заголовок, описание и промежутки;
видимая высота ограничена viewport. Более длинное содержимое прокручивается
внутри панели.

Естественный контейнер `.lab-sheet-panel-content` служит входом измерения.
Высота `.lab-sheet-panel-body` зависит от положения и движения панели,
поэтому область прокрутки не наблюдается как источник естественного размера.
Изменение только заголовка или содержимого после commit renderer должно
пересчитать `Flex` без нового commit.

Уведомления `ResizeObserver`, окна и `visualViewport` объединяются в один
отменяемый кадр. Пересчёт не записывает размер в текущем цикле доставки
`ResizeObserver`; неизменившиеся размеры и промежутки не записываются повторно.
Прямое обновление использует актуальный размер и отменяет ожидающий пересчёт.
Отключение компонента освобождает наблюдатель и ожидающий кадр. Постоянного
цикла кадров для измерения нет.
