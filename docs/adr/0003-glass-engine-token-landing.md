# ADR-0003. Приземление токенов движков liquid-glass / progressive-blur

Статус: принято полностью (владелец, 2026-07-04). Пункты B/C — «остальное
окей и логично»; пункт A — «принимаю» после добавления протокола
вариативности (§2.1). Тех-долг §4 закреплён задачей #41. Зона: канон
2026-07-01 «материал — флаг Glass/Blur/Solid; настоящий Glass приземляется
с ветки feat/liquid-glass».

## 1. Контекст — что есть на входе

**Движок LG** (`prototypes/liquid-glass/liquid-glass.js`) — `attach(el, opts)`
+ `supportsRefraction()`. При attach читает из computed style СЕМЬ числовых
параметров: `--lg-refraction`, `--lg-depth`, `--lg-dispersion`, `--lg-radius`
(blur), `--lg-saturate`, `--lg-brightness`, `--lg-contrast`; `opts` их
переопределяет. Радиус скругления движок берёт НЕ из токена, а из computed
`border-radius` (`--lg-corner` в прототипе лишь питает сам `border-radius`).
`--lg-tint` / `--lg-tint-opacity` — чисто декларативные: JS их не видит,
прототипный CSS красит `background-color: rgb(var(--lg-tint) /
var(--lg-tint-opacity))`.

**Движок PB** (`prototypes/progressive-blur/`) — полоса прогрессивного блюра;
токены `--pb-from`, `--pb-to`, `--pb-stops`, `--pb-levels`, `--pb-feather`.

**Приёмная зона** — `@labpics/ui-materials`: владеет МЕХАНИКОЙ, никогда
цветом; приватные `--_*`-переменные (`--_base`, `--_base-paint`, `--_blur`,
`--_saturate`); ось `tier × theme × mode`, `data-material="solid|glass|blur"`
при нулевом изменении разметки. Цвет — только из контракта `--lab-*`
(`--lab-bg-material-<tier>-01/02`; альфа 01-слоя = плотность стекла).

**Закон ядра** (core-CONTRACT §2): компонент читает только `--lab-mat-*` /
`--lab-elevation-*`; примитивы и приватные механики ему недоступны.

Прототип `glow/` (`--glow-core/halo/x/y`) — вне зоны этой главы; упомянут,
чтобы зафиксировать: его токены НЕ входят в это приземление.

## 2. Решение A — таблица приземления токенов

Принцип: токены движков — НЕ публичный контракт. Публичная поверхность
остаётся прежней: `data-material` + tier-классы + `--lab-*`. Всё, что
приземляется, уходит в приватный `--_*`-слой `ui-materials`.

### Liquid Glass

| Токен прототипа | Судьба | Приземление | Обоснование |
|---|---|---|---|
| `--lg-refraction` | приземляется | `--_lg-refraction` | сила преломления; параметр SVG-фильтра |
| `--lg-depth` | приземляется | `--_lg-depth` | глубина линзы; входит в geoKey карты |
| `--lg-dispersion` | приземляется | `--_lg-dispersion` | хроматическая дисперсия |
| `--lg-radius` | сливается | `--_blur` (существующий) | лестница blur(48/128px) остаётся за `tier × mode` |
| `--lg-saturate` | сливается | `--_saturate` (существующий) | дубль механики — второго токена не будет |
| `--lg-brightness` | приземляется | `--_lg-brightness` | новый приватный |
| `--lg-contrast` | приземляется | `--_lg-contrast` | новый приватный |
| `--lg-corner` | НЕ приземляется | — | движок читает computed `border-radius`; отдельный токен = второй источник истины |
| `--lg-tint` | НЕ приземляется | — | цвет только из `--lab-bg-material-<tier>-01` (закон: механика, не цвет) |
| `--lg-tint-opacity` | НЕ приземляется | — | плотность стекла = альфа 01-слоя контракта цвета |

### 2.1 Вариативность: приватность — дефолт, не потолок

Возражение владельца (2026-07-04): «если потребитель (дизайнер/бизнес) не
сможет настраивать стекло под себя — это хардкод семантики, обесценивание
ручек, нивелирование вариативности». Ответ контракта:

- **Ручки не исчезают** — они перепривязываются осями `tier × mode × theme`.
  Дизайнер настраивает стекло тем же жестом, каким настраивает весь
  остальной DS: выбором тира/моды и цветовым контрактом, а не семью
  физическими коэффициентами на каждом элементе.
- **Асимметрия дверей.** Добавить публичную ручку позже — дёшево и
  обратимо; забрать опубликованную — breaking change навсегда. Поэтому
  старт приватный: это отложенное право, а не запрет.
- **Физика ≠ намерение.** `refraction/dispersion/depth` по отдельности — не
  дизайн-решения, а внутренности движка; их публичность ломает гарантии
  (легабилити-гвард, деградация, байт-идентичный кэш фильтра). Референс:
  Apple в Liquid Glass даёт варианты материала (regular/clear), не
  коэффициенты физики.
- **Протокол тюнинга.** Появился реальный кейс «бизнес хочет своё стекло» →
  отдельным решением заводится ОДНА публичная семантическая ручка со шкалой
  (например `--lab-glass-intensity`), ремапящаяся внутри на связку
  физических. Экспозиция семи сырых коэффициентов не происходит никогда.

### Progressive Blur

| Токен прототипа | Судьба | Приземление |
|---|---|---|
| `--pb-from`, `--pb-to` | приземляются | `--_pb-from`, `--_pb-to` |
| `--pb-stops` | приземляется | `--_pb-stops` |
| `--pb-levels` | приземляется | `--_pb-levels` |
| `--pb-feather` | приземляется | `--_pb-feather` |

PB — полосная механика (тулбары/края скролла), отдельный приватный блок.
Публичная поверхность PB (класс? примитив-компонент?) — решение следующей
главы; здесь фиксируется только токен-слой.

## 3. Решение B — API: декларативный класс, attach() приватен

**Выбор: declarative-first.** `attach()` / `supportsRefraction()` НЕ
экспортируются потребителю; движок становится внутренним модулем
`ui-materials` (`packages/materials/src/engine/`). Рантайм `ui-materials` сам
апгрейдит поверхности `data-material="glass"`, когда `supportsRefraction()`
истинен; иначе остаётся текущий CSS-стек (01-слой + `blur(48px)`).

Почему не публичный attach-API:

- Ось материала обещает «нулевое изменение разметки» — императивный вызов на
  каждую поверхность ломает это обещание.
- Закон ядра: компонент читает только `--lab-mat-*`; публичный JS-API движка —
  второй, неконтрактный вход в механику.
- Деградация становится свойством системы, а не дисциплиной потребителя:
  CSS-стек — базовая истина, SVG-преломление — прогрессивный апгрейд
  (SSR-безопасно; фильтр байт-идентичен и кэшируется, ре-attach без
  пересоздания узлов).

## 4. Судьба заглушки в packages/core

- `glass.css` — back-compat шим поверх `materials.css`: остаётся без
  изменений до перевода потребителей (TODO в файле в силе).
- `theme.ts` `MATERIALS = ['ambient', 'solid', 'glassy']` — алиас `glassy`
  живёт до главы миграции на флаг-модель Glass/Blur/Solid; тип не трогаем.
- Ambient-примитивы `materials.css` (`--lab-ambient-*`) — заменяются в
  следующих главах, когда `ui-materials` примет движок; ch-01 не меняет
  рантайм-код вообще.

**Против забвения** (владелец: «не люблю технические долги»): все три пункта
сноса закреплены задачей #41 трекера; она блокируется главой переноса движка
(ch-02) и не может быть закрыта без удаления шима, алиаса и примитивов.

## 5. Последствия

- Появляется место, куда ветка feat/liquid-glass приземляет движок, не
  расширяя публичный контракт ни на один токен.
- Прототипные плейграунды продолжают жить на `--lg-*`/`--pb-*` как локальных
  ручках — переименование происходит на границе пакета, не в прототипах.
- Риск перфа (SVG-фильтр на поверхность) локализован в приватном рантайме
  `ui-materials` — его можно выключить флагом моды, не трогая потребителей.
