# ADR-0004. Acrylic и парити материалов: коридорная гарантия + оракул парити

Статус: **частично реализовано** (2026-07-08). Чертёж задачи #16 «Поверхности:
Acrylic + политика фонов». Приземлены **коридорная модель гарантии** (Решение 2),
построенные на ней задачи #52 (байт-точный композит) и #58 (лестница гарантий
текста на сложном фоне), и **рецепт Acrylic** (Решение 1) — см. «## Статус
реализации» ниже. НЕ реализован: парити-оракул CAM16-UCS ΔE (Решение 3/4) —
остаётся чертежом задачи #16 (дорогой планируемый оракул по расписанию).

## Статус реализации (2026-07-06)

Приземлено в `@labpics/ui-materials` (одним PR поверх этого ADR):

- **Решение 2 — коридор.** `evaluateTier(…, { backdrop })` принимает
  `BackdropCorridor` (по умолчанию `[black, white]` — байт-идентично прежнему
  поведению); `bandOverCorridor` / `worstContrastOverBand` — общие примитивы
  (одна математика, без дубля); `cornerCorridor` / `unionCorridor` строят коридор
  из региона и из двух смежных регионов. Выбор API: коридор — это две **цветовые**
  границы (per-channel min/max), а не пара L-скаляров (per-channel монотонность —
  честная граница; L-скаляры теряют структуру). Консервативно: угловой коридор
  ограничивает достижимое множество СНАРУЖИ — гарантия не переобещает.
- **#52 — байт-точный композит.** `compositeOverByte` (round-half-even = байт
  дисплея) доказан побайтно против SSOT lab-colors на 12 Figma-парах; домен
  контракта доказан tie-free; замороженный версионированный голден
  (`byte-composite-corridor-golden.test.ts`); браузерный дифференциал сведён к
  байт-в-байт (без L-допуска), проверен на Chromium+WebKit (зазор 0).
- **#58 — лестница.** `legibility-ladder.ts`: solid / material / image(readable) /
  tainted / boundary → либо доказанный коридор, либо принудительный scrim-пол
  (`computeScrimFloor`). Резолвер СТРУКТУРНО не может вернуть `guaranteed` для
  tainted — это ловит тест, а не ревьюер.

Приземлено волной 5 (2026-07-08) — **рецепт Acrylic (Решение 1)**:

- **Ось материала расширена** значением `data-material="acrylic"` (`material.css`,
  `MaterialMode`). Рецепт переиспользует лестницу — ни одной новой величины:
  blur = `--_blur-glass` (48px, Figma BG-blur Base ∈ Fluent 30–60px),
  saturate = `--_saturate-on` (180%).
- **Тинт straight-alpha** (тот же `--lab-bg-material-<tier>-01`, что у glass).
  `PROVENANCE`: `DECLARED`-размен `kind: declared-tradeoff` — labui кладёт тинт
  straight-alpha (как весь `compositeOver`-стек), НЕ Fluent-смесью luminosity/
  exclusion: смесь сломала бы байт-точную α-границу-гарантию. Следствие: acrylic
  использует тот же тинт над тем же коридором `[0, 1]`, что glass (множитель `C`
  не измерен), поэтому его α-граница-вердикт **тождествен** glass — ни одной новой
  unguaranteed-пары.
- **Шум ~2%** — data-URI PNG **одной генерации** (не рантайм: `feTurbulence`
  пересчитывался бы каждый кадр; декодированный PNG растеризуется один раз).
  `PROVENANCE`: 2% наследуется из ADR-0002 §1, запечено в АЛЬФУ пикселей
  (`5/255 ≈ 1.96%`); тайл 48×48 — `DECLARED figma-anchor`-аналог (размер зерна),
  тайлится на интринзик-размере (`background-size: auto`, без magic-px). Генератор
  `packages/materials/scripts/build-acrylic-noise.ts` детерминирован (фикс-сид,
  PNG-энкодер на `node:zlib`, без бинаря в git), гейтится `check-generated` и
  декод-тестом ассета.
- **Политика фонов** (`background-policy.ts`): `LIVE_BLUR_MODES` = {glass, blur,
  acrylic}, `canNest` (запрет вложенного live-блюра, Решение 4), `MATERIAL_FILL_FAMILY`
  = `--lab-bg-material-*` (семейство собственной заливки материала).
- **Деградации** расширены на acrylic (нет backdrop-filter / reduced-transparency /
  contrast:more / forced-colors → solid-канон той же целевой точки, зерно снято —
  Решение 4 «acrylic → solid той же целевой точки»).

НЕ приземлено (остаётся чертежом): множитель сжатия коридора `C` (Решение 2,
«требует измерения»; до замера acrylic консервативно наследует `[0, 1]`), парити-
оракул и бюджет ΔE (Решение 3/4).

Зона: продолжает ADR-0002 §1 (флаги эффектов Glass | Blur, волна 3
«Blur/acrylic анатомия рядом с liquid-glass») и ADR-0003 (приземление токенов
движков). НЕ трогает приземлённый контракт Liquid Glass.

Именование ниже опирается на реальные символы пакета `@labpics/ui-materials`
(`material-guarantee.ts`, `luminance.ts`, `material.css`, `engine/`) и на
контракт цвета `@labpics/colors` (`--lab-bg-material-<tier>-01/02`).

## Контекст — что уже есть

- **Ось материала** (`material.css`): `data-material="solid|glass|blur"` +
  тир-модификаторы `.lab-material--{base,muted,soft,subtle,elevated}` при нулевом
  изменении разметки. Цвет — только из контракта: `--lab-bg-material-<tier>-01`
  (полупрозрачный тинт, его альфа = плотность) над `--lab-bg-material-<tier>-02`
  (непрозрачная база). SOLID-канон = 01 над 02, непрозрачно, и он же —
  универсальный фолбэк всех деградаций.
- **α-boundary гарантия** (`material-guarantee.ts`): для стекла легабилити
  доказывается на всём диапазоне неизвестного фона. Диапазон ограничен двумя
  экстремумами в том же пространстве, что красит браузер (straight-alpha в
  гамма-кодированном sRGB, `compositeOver`): `effLow = L(тинт над чёрным)`,
  `effHigh = L(тинт над белым)`. Вердикт `guaranteed` = `worstContrast` по всему
  коридору `[effLow, effHigh]` ≥ пол WCAG AA (`WCAG_AA_NORMAL = 4.5`), включая
  вырожденный случай «яркость лейбла внутри коридора → 1:1». Полярность лейбла —
  `commitLabel` (кандидат с наибольшим контрастом на солид-каноне).
- **Движок Glass** (`engine/`): преломление через SVG `feDisplacementMap` (линза,
  гнёт фон); приватные ручки `--_lg-refraction|depth|dispersion|brightness|contrast`;
  байт-идентичный кэш карт; деградации в `material.css` схлопывают glass/blur в
  solid.
- **Пробел**: `blur` сегодня — просто более сильный backdrop-blur (`--_blur-blur:
  128px`) без анатомии Fluent (тинт-смесь, шум) и без собственной модели гарантии.
  Acrylic не отделён от Liquid Glass ни рецептом, ни моделью парити между
  материалами.

## Решение 1 — контракт материала Acrylic (Fluent-класс)

Acrylic — **рассеяние** (низкочастотный Gaussian-блюр диффундирует фон), в
отличие от Liquid Glass — **рефракции** (линза `feDisplacementMap` смещает выборку
фона). Это разные физики, не два пресета одного эффекта.

**Рецепт** (анатомия Fluent, ADR-0002 §1 «подсмотреть анатомию acrylic»):

1. `backdrop-filter: blur(R)` — R в диапазоне Fluent 30–60px (референс WinUI
   in-app acrylic). `PROVENANCE`: диапазон — внешний референс; конкретный R
   labui переиспользует лестницу Figma BG-blur, уже приземлённую как
   `--_blur-glass: 48px` / `--_blur-blur: 128px`. Точное значение R для acrylic —
   `DECLARED`-величина `kind: figma-anchor`, заземляется замером в Figma при
   реализации (дисциплина ADR-0002 §1, не рукописный hex).
2. `saturate(S)` — переиспользует `--_saturate-on: 180%` (дубль механики, не новый
   токен; ADR-0003 §2 слил `--lg-saturate` в `--_saturate`).
3. Тинт из контракта — `--lab-bg-material-<tier>-01` с альфой α; смесь
   luminosity/exclusion (Fluent) кладёт тинт так, чтобы он не «выцветал» на
   светлом и не «глох» на тёмном фоне. `PROVENANCE`: тип смеси — внешний референс;
   если labui выберет упрощение до straight-alpha (как сегодня в `compositeOver`),
   это `DECLARED`-размен, а не молчаливое отклонение.
4. Шум ~2% — фиксированный ассет data-URI PNG **одной генерации**, не рантайм
   (наследуется дословно из ADR-0002 §1; не новое число). Мелкое зерно снимает
   бандинг градиентов под блюром — это и делает акрил «чище фонового блюра».

**Пресеты за одним токен-контрактом.** Три пресета:

| Пресет | Физика | Backdrop | Гарантия |
|---|---|---|---|
| `acrylic-in-app` | блюр контента внутри окна | live, лёгкий блюр | коридорное неравенство (Решение 2) |
| `acrylic-background` | блюр того, что за окном | live, тяжёлый блюр | коридорное неравенство |
| `mica` (третий) | **opaque-tint**, без live-блюра | тинт из обоев, статичен | тривиальна (непрозрачно, как solid-канон) |

Mica — вырожденный случай: непрозрачный материал, чей тинт выведен из обоев рабочего
стола; в вебе = solid-канон с обойно-производным тинтом, гарантия держится всегда.

Все три адресуются через **существующее семейство** `--lab-bg-material-*` (плюс,
при нужде, ток­ен выбора пресета). Предложенное в задаче имя `--lab-material-*` —
это предложение сверить/унифицировать имя семейства на этапе реализации; **новый
токен-контракт этот ADR не вводит** (асимметрия дверей, ADR-0003 §2.1: добавить
публичную ручку позже — дёшево; забрать — breaking).

## Решение 2 — коридорная гарантия яркости

Блюр — **низкочастотный фильтр**: он усредняет фон в пятно, сжимая диапазон
яркости, который поверхность реально видит под текстом. Тинт с непрозрачностью α
даёт результат яркости

```
Y_result ∈ α·Y_tint + (1 − α)·[Y_min, Y_max]
```

где `[Y_min, Y_max]` — достижимый коридор яркости фона **после** блюра. Это
обобщение уже имеющейся математики: сегодня `evaluateTier` фиксирует коридор
двумя экстремумами резкого фона `[effLow, effHigh] = [L(тинт над чёрным), L(тинт
над белым)]`, то есть частный случай `[Y_min, Y_max] = [0, 1]`.

**α и цвет тинта — РЕШЕНИЕ неравенства, не ручной ползунок.** Требование:

```
worstContrast(лейбл, Y_result) ≥ пол   по всему коридору [Y_min, Y_max]
```

Логика «худшая точка внутри полосы» уже реализована в `material-guarantee.ts`
(случай `labelLuminance ∈ (effLow, effHigh) → 1:1`), а композит и WCAG-яркость —
в `luminance.ts` (`compositeOver`, `relativeLuminance`, `contrastRatio`). Acrylic
**переиспользует** эту машину, лишь параметризуя границы коридора вместо жёстких
чёрный/белый.

**Провенанс коридора — честно.** Насколько блюр сужает `[Y_min, Y_max]` относительно
`[0, 1]`, зависит от радиуса блюра против пространственной частоты фона. Множитель
сжатия `C ∈ (0, 1]` — **число, требующее ИЗМЕРЕНИЯ** (empirical-inventory,
меряется харнессом Решения 4), а не декларации на глаз. Пока `C` не измерен,
acrylic **консервативно наследует** коридор стекла `[0, 1]` и, значит, тот же
гарантированный набор тиров, что glass (см. README «Unguaranteed pairs»). Это
исключает магическое число в поставке: узкий коридор — опциональное усиление
поверх измерения, а не допущение.

Привязка к коду: расширить `TierFill`/`evaluateTier` параметром коридора
`[Y_min, Y_max]` со значением по умолчанию `[0, 1]` (обратная совместимость: glass
= сегодняшнее поведение). Вердикт остаётся `guaranteed`/`worstContrast`.

## Решение 3 — парити-модель материалов

**SSOT роли** = целевая точка **CAM16-UCS (J′/M/h)** + **контраст-класс** (пол
читаемости). Это модель ролей `@labpics/colors` (ADR-0002 оперирует dJ′ в
CAM16-UCS; роли несут контраст-полы). Роль — это «куда целимся перцептивно и какой
контраст обязаны держать», а не hex на материал.

Два пространства, две работы (оба уже в системе): **гарантия легабилити** живёт в
WCAG-яркости (`luminance.ts`), **идентичность роли** — в CAM16-UCS (lab-colors).

**Три солвера** переводят одну роль в три материала:

| Материал | Солвер | Механизм |
|---|---|---|
| solid | прямой резолв | непрозрачный композит 01 над 02 (`compositeOver`) попадает в целевую точку напрямую |
| acrylic | коридорное неравенство | подобрать (α, тинт) так, чтобы воспринимаемая точка ≈ цель И `worstContrast` ≥ пол по коридору (Решение 2). Цель недостижима при нужном контрасте → пометка unguaranteed → деградация в solid |
| glass | rim/scrim-пол как констрейнт | линза искажает локальный цвет (смещённая выборка), плоская целевая точка часто недостижима → вводится **пол**: минимальный непрозрачный scrim/rim под текстовой зоной, гарантирующий контраст там, где линза не может. Согласуется с README «text on glass uses only guaranteed surface tokens» и с frost-фолбэком |

**Парити-оракул** поверх CH-6b-харнесса (паттерн `apps/docs/tests/materials-flag.spec.ts`:
реальный браузер, резолв токенов, композит на `<canvas>`, `getImageData`):

1. Отрисовать **одну роль** на трёх материалах (solid / acrylic / glass) над
   идентичными фонами.
2. Замерить **фактический** крашенный цвет (`getImageData`, усреднение по патчу
   ≥ одного тайла шума — Решение 4).
3. Перевести в CAM16-UCS, проверить `ΔE(CAM16-UCS)` между любой парой материалов
   ≤ **бюджет** И одинаковый контраст-класс у всех трёх.

**Бюджет ΔE — DESIGN-CHOICE-интервал 2–3 ед.** Обоснование: `ΔE(CAM16-UCS) ≈ 1` —
порог едва заметной разницы (JND); материалы **законно** различаются
микро-текстурой (блюр/шум/линза), поэтому требовать `ΔE → 0` неверно — это стёрло
бы саму разницу материалов. Бюджет обязан быть > JND (иначе ловит текстуру как
дефект), но < сдвига тона/светлоты (иначе пропускает реальный рассинхрон роли).
`PROVENANCE`: интервал `[2, 3]` — `DECLARED`-размен `kind: declared-tradeoff`;
точное значение внутри интервала заземляется при первом прогоне оракула (как
DECLARED-размены ADR-0002 §6), не берётся с потолка.

## Решение 4 — тест-матрица (классы Фаулера)

| Ось | Значения | Класс | Что ловит |
|---|---|---|---|
| Тема | светлая / тёмная | А (Integration) | асимметрия контракта по `data-theme` |
| Экстремальные обои | чёрный / белый / фото (высокочастотное) | В (Differential/Property) | худший случай коридора; фото — проверка утверждения о сжатии `C` |
| reduced-transparency | acrylic → solid **той же целевой точки** | А + Б (Regression) | фолбэк меняет материал, НЕ цвет роли (диф против solid-солвера) |
| DPR | 1 / 2 / 3 | В (Property) | масштаб тайла шума и радиуса блюра |
| Вложенность материалов | acrylic-в-acrylic, glass-в-glass | А (инвариант) | двойной live-блюр = шов; политика: запрет вложенного live-блюра (как glass-on-glass в README) |
| Шум | замер усредняет ≥ 1 тайла шума | В (Property/инвариант) | шум ~2% НЕ двигает `ΔE` — иначе замер парити ловил бы зерно как рассинхрон |

Порядок — дёшево→дорого: юнит α-boundary коридора (как `alpha-boundary.test.ts`)
→ дифференциал коридора против браузерного композита (как differential-тест в
`materials-flag.spec.ts`) → парити-оракул в реальном браузере. Дорогой оракул — по
расписанию, дешёвые инварианты — per-PR.

## Чего этот ADR НЕ делает

- **Не реализует** ни рецепт, ни солверы, ни оракул — это чертёж задачи #16.
- **Не меняет контракт Liquid Glass** ADR-0003: приватные `--_lg-*`, computed
  `border-radius` как источник скругления, байт-идентичный кэш фильтра и
  деградации остаются как есть. Коридорная модель добавляется **рядом**, не
  переписывает α-boundary стекла.
- **Не вводит нового токен-контракта** (`--lab-material-*` — предложение
  унификации имени существующего `--lab-bg-material-*`, решается в реализации).
- **Не вводит магических чисел без декларации.** Каждое новое число — сразу с
  провенансом в стиле empirical-inventory lab-colors:
  - блюр R (30–60px) — внешний референс Fluent + `DECLARED figma-anchor` для labui;
  - бюджет `ΔE` (2–3) — `DECLARED-tradeoff`, заземляется прогоном оракула;
  - множитель сжатия коридора `C` — **не декларируется**, помечен как
    **требующий измерения**; до замера acrylic наследует `[0, 1]` (магическое
    число не поставляется);
  - шум ~2% — наследуется из ADR-0002, не новое.

## Последствия

- Появляется место, куда задача #16 приземляет Acrylic, не расширяя публичный
  контракт и не трогая Liquid Glass.
- Гарантия обобщается с двух фиксированных экстремумов до параметризованного
  коридора — один класс математики покрывает solid (тривиально), acrylic
  (неравенство) и glass (частный случай `[0, 1]` + rim/scrim-пол).
- Парити между материалами становится **измеримым свойством** (оракул + бюджет
  `ΔE`), а не дисциплиной глаза.
- Открыто до реализации: точный R блюра (figma-anchor), точка внутри бюджета
  `ΔE`, измерение множителя `C`, финальное имя семейства токенов, тип смеси
  (luminosity/exclusion против straight-alpha).
