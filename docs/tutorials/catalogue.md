# Первый запуск каталога

Этот путь знакомит с веб-компонентами Lab UI из исходников. Он заканчивается
работающей страницей компонента с вариантами оформления и примерами API.

## Подготовить проект

Установите Git, Node.js версии не ниже `engines.node` и pnpm версии
из `packageManager` в [package.json](../../package.json).
Затем выполните:

```sh
git clone https://github.com/Labpics-Team/labui.git
cd labui
pnpm install --frozen-lockfile
pnpm build
pnpm --filter @labpics/ui-docs dev
```

Сборка workspace нужна до запуска каталога: его импорты используют
собранные входы пакетов. Если установка или сборка завершилась ошибкой,
исправьте её перед запуском Vite. Файл `pnpm-lock.yaml` фиксирует зависимости;
для первого запуска его не нужно пересоздавать.

## Открыть компонент

Откройте напечатанный Vite адрес. На начальной странице перейдите по ссылке
**Component documentation**, затем выберите **Button**. Прямой путь к нему —
`/components.html?component=button`.

Страница показывает свойства компонента, варианты и примеры. Измените тип,
оформление и размер кнопки. Переключите тему и сравните состояния.
Так можно увидеть API и результат одного компонента до подключения
к своему приложению.

Для сравнения Web Component, React и Vue откройте `/button.html`.
Обе страницы входят в [приложение каталога](../../apps/docs/).

## Собрать каталог

После сборки workspace выполните:

```sh
pnpm --filter @labpics/ui-docs build
pnpm --filter @labpics/ui-docs preview
```

Preview обслуживает готовую сборку. Адрес задаётся скриптом `preview`
в [манифесте каталога](../../apps/docs/package.json); `dev` использует
адрес, выбранный Vite.

Для подключения компонента к приложению перейдите к
[практическому руководству](../how-to/use-components.md).
