# Триаж отклонений закона уровней — D1 / D2 / D5 (#99)

Статус: **ОТКРЫТО — вердикт за владельцем.** Документ только предлагает
классификацию каждого из трёх открытых отклонений гейта закона уровней
(PR #117, ветка `test/level-law-gate`). Гейт, его вердикты и живые ассерты
НЕ тронуты; skip-лист `packages/colors/test/level-law.test.mjs` не менялся.

Отклонения D3 / D4 / D6 уже классифицированы «иной закон по дизайну» в шапке
теста и здесь не рассматриваются. Здесь — три **ОТКРЫТЫХ**: D1, D2, D5.

## Как воспроизвести

```
# замер триажа (полные таблицы ниже):
node packages/colors/level-law-triage.mjs

# сам гейт (зелёный, отклонения в карантине skip-листа):
cd packages/colors && node node_modules/vitest/vitest.mjs run test/level-law.test.mjs
#  → Tests  61 passed | 6 skipped (67)
```

Замерочный скрипт `packages/colors/level-law-triage.mjs` — отдельный, читает
ту же эмиссию `packages/colors-stub/contract.css` через публичный API
`level-law.mjs` (каскад last-wins + var()-резолв + тон oklab-J′, translucent-
композит в gamma-sRGB). Он ничего не проверяет как гейт — только печатает
таблицы и статус альтернативных инвариантов.

Метрика тона везде — **oklab-J′** и его прирост от фона темы **dJ′**
(light bg `#FFFFFF` J′=100.00; dark bg `#101012` J′=17.39). Это та же метрика,
которой меряет гейт: для монотонности и относительных сравнений семей, не
паспортная CAM16-цель.

## D1 — сентимент-когорта ≠ нейтраль-лестница (fill/border)

### Гипотеза (из шапки #117)

Две физики лестниц: нейтраль = HIG system-fill (α 0.2/0.161/0.122/0.078),
сентименты = тинт (α 0.122/0.078/0.039/0.02, байт-единообразно по 5 семьям).
Закон «уровень = целевой тон» держится в **НЕПРОЗРАЧНОСТИ (α)**, не в dJ′.

Числа из шапки #117 (fill light primary: neutral −8.06, brand −5.42 Δ+2.63,

однознаковая (light +, dark −): сентименты стабильно СВЕТЛЕЕ нейтрали на своём
уровне — это следствие меньшей α тинта, не хаос.

### Проверка гипотезы — альтернативный инвариант «α-лестница»

α-лестница fill по уровням (MONO = строго убывает primary→quaternary):

| тема | семья | primary | secondary | tertiary | quaternary | MONO |
|---|---|---|---|---|---|---|
| light | neutral | 0.200 | 0.161 | 0.122 | 0.078 | да |
| light | сентименты (×5) | 0.122 | 0.078 | 0.039 | 0.020 | да |
| dark | neutral | 0.361 | 0.322 | 0.239 | 0.161 | да |
| dark | сентименты (×5) | 0.122 | 0.078 | 0.039 | 0.020 | да |

Border-когорта (та же физика): `strong` — opaque (α=1) контраст-якорь (это D3,
вне тон-лестницы по дизайну); `base`/`soft` — translucent-тинт, base>soft
монотонно во всех семьях обеих тем (сентименты 0.200/0.122 тема-инвариантно;
нейтраль light 0.161/0.078, dark 0.200/0.122).

**Итог замера: α-лестница монотонна во ВСЕХ семьях обеих тем — без исключений.**
Нейтраль несёт тема-зависимую system-fill α-лестницу, сентименты — тема-
инвариантную тинт-α-лестницу. Две лестницы, обе монотонны. Байт-единообразие α
сентиментов внутри уровня уже под живым ассертом гейта; НОВОЕ здесь — доказанная
монотонность α **вдоль уровней внутри каждой семьи**.

### Предлагаемая классификация

**ОТКРЫТО → «иной закон (α-лестница)»**, по образцу D3/D4/D6. «Уровень = целевая
непрозрачность» держится без исключений; «уровень = единый целевой тон (dJ′)»
между двумя когортами не держится ПО ДИЗАЙНУ (system-fill vs tint — разные
физики). Аспирационный dJ′-инвариант остаётся красным (потому skip); движок без
per-hue dJ′-якоря — ADR-0002 §2 «dJ′-якоря» помечено аспирационно.

### Предлагаемая формулировка альтернативного инварианта

> Внутри каждой fill-семьи α строго убывает primary→quaternary (нейтраль —
> тема-зависимая system-fill лестница; 5 сентиментов — общая тема-инвариантная
> тинт-лестница). Для border — base>soft внутри семьи; strong вне лестницы (D3).

Если владелец примет — этот инвариант можно поднять из аспирационного skip в
живой ассерт (α-монотонность вдоль уровней), а dJ′-кросс-когортный ассерт
оставить постоянным skip с обоснованием «две физики».

### Вердикт — за владельцем

Развилка: (а) принять «иной закон (α-лестница)» и заморозить dJ′-кросс-когортный
skip навсегда; либо (б) если нужен единый dJ′ — это уже **дефект движка**
(добавить per-hue dJ′-якоря сентиментам), а не doc-триаж. **Решает владелец.**

## D2 — оттенок ломает единообразие тона при равной α

### Гипотеза (из шапки #117)

При байт-равной α сентименты дают разный dJ′ (fill light primary: brand −5.42
vs warning −2.95, Δ 2.47). Тон = f(α, светлота тинта); равная α ≠ равный тон.
Тот же класс, что D1.

### Воспроизведённые числа — dJ′ по светлоте солидного тинта (фиксированная α)

`solidJ′` — oklab-J′ солидного (непрозрачного) цвета семьи; сортировка по
возрастанию светлоты тинта.

|---|---|---|

| quaternary | −0.9644 | +0.8477 |

### Проверка гипотезы

Зависимость **системная и сильная**: |r| = 0.85…0.96 на всех уровнях обеих тем.
Знак объясняется физикой композита над фоном темы: в light (bg J′=100) светлее
тинт = ближе к фону = меньше |dJ′| (r < 0); в dark (bg J′=17.4) светлее тинт =
дальше от фона = больше |dJ′| (r > 0). То есть равная α физически НЕ МОЖЕТ давать
равный dJ′, пока солидные тинты семей различаются по светлоте — гипотеза
подтверждается.

Оговорка честности: строгий межсемейный порядок |dJ′| по одной лишь светлоте
тинта **НЕ выполняется** (в light danger 65.42 даёт |dJ′| 5.30 > info 64.04 → 4.39,
инверсия). Причина — тон композита зависит не только от светлоты, но и от хромы
тинта (danger высокохромен, C=0.232). Поэтому строгий кросс-семейный инвариант
«порядок по светлоте» предлагать НЕЛЬЗЯ — он ложен.

### Предлагаемая классификация

**ОТКРЫТО → «иной закон (следствие физики тинта)»** — тот же класс, что D1.
«Единый dJ′ по семьям при равной α» — не дефект, а физически невозможное
требование при разных тинтах. Не чинить как рассинхрон.

### Предлагаемая формулировка альтернативного инварианта

> Внутри каждой сентимент-семьи |dJ′| монотонен по уровню (уже живой ассерт
> гейта) при байт-равной α сентиментов на уровне (уже живой ассерт). Межсемейный
> разброс dJ′ при равной α — предсказуемое следствие светлоты тинта
> (|r|≈0.85…0.96), но не строгий порядок (вклад хромы). Единого dJ′ по семьям
> закон НЕ требует — по построению.

Новых живых ассертов D2 не добавляет: два нужных инварианта уже в гейте;
кросс-семейный dJ′-ассерт остаётся аспирационным skip с обоснованием физики.

### Вердикт — за владельцем

Принять «иной закон (следствие физики тинта)» и держать dJ′-кросс-семейный skip
постоянным — либо, если владелец хочет единый воспринимаемый тон сентиментов,
это **задача движка** (per-hue коррекция α/светлоты под целевой dJ′), не doc.
**Решает владелец.**

## D5 — inverted-label primary вырожден (dJ′ 0, обе темы)

### Гипотеза (из шапки #117)

Figma-мост opposite-theme (renderScope, не движок); primary совпадает с фоном на
со-теме → dJ′ 0.

### Воспроизведённые числа — label-inverted по уровням

| тема | уровень | сырое значение | dJ′ | статус |
|---|---|---|---|---|
| light | primary | `rgb(255 255 255)` | 0.00 | **ВЫРОЖДЕН** (|dJ′|<0.5) |
| light | secondary | `rgb(176 176 185 / 0.722)` | −17.17 | не вырожден |
| light | tertiary | `rgb(176 176 185 / 0.522)` | −12.27 | не вырожден |
| light | quaternary | `rgb(176 176 185 / 0.322)` | −7.45 | не вырожден |
| dark | primary | `rgb(16 16 18)` | 0.00 | **ВЫРОЖДЕН** (|dJ′|<0.5) |
| dark | secondary | `rgb(60 60 67 / 0.722)` | 13.72 | не вырожден |
| dark | tertiary | `rgb(60 60 67 / 0.522)` | 10.08 | не вырожден |
| dark | quaternary | `rgb(60 60 67 / 0.322)` | 6.28 | не вырожден |

Вырожден только `primary` (потому в `KNOWN_DEGENERACIES` лишь `label-inverted
primary {light,dark}`, без secondary/tertiary/quaternary). Причина проста:
`primary` непрозрачен и равен фону измеряемой темы — light `rgb(255 255 255)` =
`#FFFFFF` = light bg; dark `rgb(16 16 18)` = `#101012` = dark bg. Вторичные уровни
translucent → композитятся в отличимый тон, не вырождаются.

### Проверка гипотезы — происхождение значения

Прослежено в `generate-contract.mjs`: движок эмитит только свои роли, остальное —
мост из замороженного `figma-reference.css` (`renderScope`, else-ветка,
строка 141: `${anchorValue}; /* мост: Figma-якорь */`). Эмиссия в `contract.css`:

```
--lab-label-inverted-primary: rgb(255 255 255); /* мост: Figma-якорь */  (light)
--lab-label-inverted-primary: rgb(16 16 18);    /* мост: Figma-якорь */  (dark)
```

Значение НЕ выведено движком (нет `translucent`/`compositeHex`-роли; отсутствует
в override-ветках закона пары и в `PROVISIONAL_BRIDGE`) — это дословный
Figma-якорь. Гипотеза подтверждается: вырождение — свойство МОСТА, не движка.
Семантически «inverted» лейбл предназначен для поверхности ПРОТИВО-полярной темы
(как статики D4); измеренный против со-темного фона он схлопывается — измеряется
не на своём хосте.

### Предлагаемая классификация

**ОТКРЫТО → «иной закон (мост, вне юрисдикции движка)»**. Значение вне контроля
движка закона уровней; его судьба решается работой по сносу bridge-мостов
замороженного референса (**эпик-задача трекера №101** — «снос bridge-мостов»;
это НЕ GitHub-PR #101 labui, который `fix(e2e): shadow dark-theme`, MERGED, к
делу не относится). Пока мост стоит — D5 постоянный «иной закон (мост)»; когда
мост снят и `label-inverted` начнёт выводиться движком/законом пары — значение
пере-деривируется и D5 подлежит повторному замеру.

### Вердикт — за владельцем

Не чинить в юрисдикции гейта уровней. Решение о сносе моста и пере-деривации
`label-inverted` — за владельцем в рамках работы №101; предрешать её здесь нельзя.
**Решает владелец.**
