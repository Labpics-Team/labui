их свойства, события и примеры. Руководства ниже описывают работу
с исходниками и действующими веб-пакетами.

## Практические руководства

- [Подключение компонентов](how-to/use-components.md) — Web Components, React, стили и материалы.
- [Подключение гидратации](ssr.md) — настройка Astro, порядок загрузки в других приложениях и передача Boolean из серверного HTML.
- [Участие в проекте](../CONTRIBUTING.md) — выбрать место изменения и проверить результат.
- [Сообщение об уязвимости](../SECURITY.md) — приватный канал и данные для воспроизведения.

Серверные входы `@labpics/ui-*/ssr` используют минимальное DOM-окружение Lit
и возвращают Declarative Shadow DOM вместе со стилями компонентов. Существующие
`fetch` и реестр компонентов хоста сохраняются. Тема и шрифты подключаются
приложением. Дополнительные DOM API и загрузку CSS-файлов серверным JavaScript
задаёт хост или сборщик: SSR-вход LabUI не устанавливает глобальные обработчики
загрузки модулей Node.
