# Устройство Lab UI

[Семантика, материалы и движение](architecture/labui-system.md) описывает
согласованное направление системы, границы движков и проверенный задел.

[Прочитанный эталон](reference/design-baseline.md) сохраняет размеры, роли
и границы проверки авторской библиотеки.

## Компоненты

[Ядро](../packages/core/) реализует компоненты, состояния,
Web Components и серверный рендеринг. Правила взаимодействия
и доступность оформляются рядом с их реализацией.

## Привязки платформ

Адаптеры подключают компоненты ядра к
[React](../packages/react/), [Vue](../packages/vue/),
[Svelte](../packages/svelte/), [Solid](../packages/solid/)
и [Astro](../packages/astro/).

[Генератор адаптеров](../packages/adapter-codegen/) управляет
общими частями кода привязок. Варианты поведения принадлежат
компоненту ядра; интеграционный код относится к адаптеру.

## Оформление

[Токены](../packages/tokens/), [цвет](../packages/colors/),
[тени](../packages/shadow/), [материалы](../packages/materials/)
и [шрифты](../packages/fonts/) задают оформление.
Необходимое значение меняется у владельца соответствующего
пакета. Локальная тема продукта использует доступные токены.

[Подключение материалов](reference/materials.md): CSS, Shadow DOM,
режимы поверхности и жизненный цикл движков.

## Примеры и проверки

[Каталог](../apps/docs/) содержит демонстрации, пользовательские
состояния и браузерные проверки компонентов.
Для запуска используйте [README](../README.md#открыть-каталог).

Исходные адреса всех пакетов и команды работы задаются
[манифестом workspace](../pnpm-workspace.yaml) и
[package.json](../package.json).
