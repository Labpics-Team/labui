# Устройство Lab UI

Lab UI связывает авторский визуал с поведением компонентов и публичными
API разных веб-фреймворков. Общий контракт позволяет менять вычислительный
или платформенный механизм, сохраняя смысл компонента для приложения.

## Компоненты и привязки

[Core](../../packages/core/) содержит Web Components на Lit, общие типы,
механизмы поведения и серверный рендеринг. Для элементов со сложным состоянием
используются соответствующие машины Zag. Простой контроль может опираться
на поведение обычного HTML-элемента.

[React](../../packages/react/) рисует DOM-элементы и использует общий контракт
типов и поведения. Vue, Svelte, Solid и Astro подключают Web Components
через свои привязки. Общие части привязок создаёт
[генератор адаптеров](../../packages/adapter-codegen/).

В термине «native React renderer», встречающемся в исходниках, native
означает обычный React/DOM renderer. Готовность SDK операционной системы
требует отдельной реализации и проверки на этой платформе.

## Кто принимает решения

Lab UI задаёт роли компонентов, отношения цветов, варианты оформления,
геометрию и авторские предпочтения. [LabColors](https://github.com/Labpics-Team/lab-colors)
вычисляет цвет; локальный [цветовой пакет](../../packages/colors/) связывает
его с семантическими ролями `--lab-*`.
[LabMotion](https://github.com/Labpics-Team/lab-motion) исполняет движение;
Lab UI задаёт цели и связывает их со временем жизни компонента.

[Materials](../../packages/materials/) владеет слоями поверхностей,
эффектами Glass/Acrylic и progressive blur. Платформенные возможности
определяют способ исполнения эффекта. Solid, Glass и Acrylic остаются
общими значениями оси материала.

## Компонент и поверхность

Sheet — компонент со своей анатомией, состояниями и взаимодействием.
Материал — способ оформления его поверхности. Переключение материала
не меняет назначения компонента. Progressive blur отдельно оформляет край
поверхности или области и не становится ещё одним материалом.

[Токены](../../packages/tokens/) связывают геометрию и типографику с общими
значениями. Компоненты потребляют семантические роли; изменение их значений
выполняется у соответствующего владельца.

Требования, которые должны сохраняться при развитии этих связей,
записаны в [справочнике инвариантов](../reference/invariants.md).
