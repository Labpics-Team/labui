# Вердикт #109 — форма стейт-токенов: `color-mix()` оверлеи

Статус: **прототип для приёмки владельца, НЕ мержить.** Все числа воспроизводимы:
`node prototypes/colormix-state-overlays/measure.mjs` (само-проверяющийся гейт).

## Вердикт: ПРИНЯТЬ ФОРМУ — условно

`color-mix()`-оверлеи вместо размножения стейт-токенов экономят **240 токенов**,
нативны (Baseline 2023), деградируют fail-safe. **НО** рецепт оверлея НЕ
универсален: наивный «тема-адаптивный сдвиг к чернилам темы» роняет WCAG на
несущих лейбл заливках в тёмной теме. Форма готова к компонентному уровню ТОЛЬКО
с контраст-осознанным рецептом (см. «Развилка рецепта») — это гейт владельца, от
него зависит API компонентов (один универсальный сдвиг vs сдвиг по классу).

## 1. Экономия токенов (замер)

80 интерактивных ролей (Fills 33 + Component-fill/border/label 27 + сентимент-
Labels 20) × 3 состояния с цветовым сдвигом (hover/pressed/selected) =
**240 токенов НЕ появится.** `disabled` = `opacity` (WCAG-exempt по 1.4.3),
`focus` = ring — вне цветового размножения. Оверлеи добавляют **0** новых токенов
ролей: тинт сдвига — существующий `--lab-label-primary`.

## 2. Честность контраста (замер; WCAG 1.4.3 распространяется на hover/focus)

Оверлей = `color-mix(in oklab, <роль>, <тинт> P%)`, P: hover 8%, pressed 14%.

| поверхность (несущая лейбл) | рецепт | light rest→pressed | dark rest→pressed |
| --- | --- | --- | --- |
| `fill-accent` × `label-on-accent` | наивный (к чернилам) | 4.52 → 5.77 ✓ | 4.51 → **3.57 ✗** |
| `fill-danger` × `label-on-danger` | наивный (к чернилам) | 4.50 → 5.75 ✓ | 4.50 → **3.58 ✗** |
| `fill-accent`/`danger` × лейбл | безопасный (к чёрному) | 4.5 → 6.3 ✓ | 4.5 → **6.3 ✓** |
| нейтраль / tinted / ghost / текст | любой | все ≥ 4.8 ✓ | все ≥ 8 ✓ |

**Корень.** Пары «заливка × лейбл-на-ней» сидят на полу 4.5 ПО ПОСТРОЕНИЮ (закон
пары = «строгая победа стороны, минимальный запас»). В тёмной теме чернила
светлые → наивный оверлей ОСВЕТЛЯЕТ заливку → она идёт к светлому `label-on-*` →
контраст рушится ниже 4.5. Затемнение (к чёрному) двигает заливку ОТ лейбла →
контраст РАСТЁТ в обеих темах. Нейтраль/ghost/текст имеют большой запас — им
безопасен любой рецепт.

## 3. Пространство смешивания: `in oklab`

Движок эмитит `oklch()` (перцептивная лестница CAM16/oklab). `color-mix(in oklab)`
консистентен: сохраняет оттенок и перцептивную светлоту (a,b масштабируются
вместе → угол оттенка держится). `in srgb` (гамма) при малых оверлеях 8–14%
отличается **суб-перцептивно** (Δhue < 3°), но на бОльших сдвигах мутит серединку
и дрейфит оттенок (CSS Color 5: srgb-микс бел/чёрн «чуть светлее», син/бел «чуть
фиолетовит»; Ottosson). Замер: dark `fill-danger` pressed Δhue(oklab↔srgb) = 2.9°,
oklab держит хрому ближе к базе. **Рекомендация: `in oklab`.**

## 4. Деградация

`color-mix()` — Baseline «Widely available» с мая 2023 (~91%: Chrome/Edge 111,
Safari 16.2 + iOS, Firefox 113); `in oklab` shipped ВМЕСТЕ с функцией, не позже
(caniuse, MDN). **Fallback fail-safe:** невалидное значение отбрасывается
CSS-каскадом ПООДИНОЧКЕ — поверхность НЕ пропадает, остаётся предыдущее/
унаследованное значение. Паттерн (см. `overlays.css`): статик-роль первой строкой
(без оверлея) + `color-mix` второй; для расходящихся правил —
`@supports (color: color-mix(in oklab, red, blue))`. Baseline labui ≥ 2023 → покрыт;
незакрытый хвост рендерит resting-цвет (без стейт-сдвига) — деградация видимости,
не поломки.

## Развилка рецепта (гейт владельца)

Для несущих лейбл заливок (accent/danger fill) в ТЁМНОЙ теме конвенция
«hover светлеет» конфликтует с полом 4.5. Варианты:

- **A. Затемнять к чёрному в обеих темах.** Безопасно, но dark-hover темнеет
  (против конвенции Material «dark = light overlay»).
- **B. Пара-fill закон резервирует headroom** над 4.5 (= макс ΔL оверлея) → тогда
  осветление легально и конвенция держится. Цена — пересчёт пар в ядре
  (@labpics/colors), semver-major.
- **C. Recheck-and-clamp.** CI-гейт клампит долю оверлея под пол на каждой паре
  (динамический P вместо фикс. 8/14%).
- **D. Рецепт по классу поверхности.** Несущие лейбл → к чёрному; нейтраль/ghost/
  текст → тема-адаптивно к чернилам.

**Рекомендация: D + гейт `recheckContrast` на CI** (переиспользовать математику
`accent-substrate-legality.test.mjs` на оверлей-вариантах — уже есть). Форма НЕ
идёт на компонентный уровень без выбора владельца: API компонентов зависит от
того, будет ли стейт-сдвиг одним универсальным рецептом или классовым.
