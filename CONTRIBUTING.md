# Участие в Lab UI

Изменение должно улучшать наблюдаемое поведение компонента, его подключение
или документацию и сохранять [инварианты системы](docs/reference/invariants.md).
Для ошибки приложите воспроизведение и ожидаемый результат; для возможности
опишите пользовательский сценарий. Обычные вопросы и предложения принимаются
в [Issues](https://github.com/Labpics-Team/labui/issues).

## Подготовить окружение

Следуйте [первому запуску каталога](docs/tutorials/catalogue.md).
Изменяйте исходники в отдельной ветке; сохраняйте закреплённый lockfile.

## Выбрать место изменения

- Поведение, состояния и общие типы компонента — `packages/core`.
- Представление в конкретном фреймворке — его пакет привязки.
- Общие генерируемые части привязок — `packages/adapter-codegen`.
- Цветовые роли, геометрия и материал — соответствующие пакеты из [карты](docs/reference/packages.md).
- Примеры и браузерные проверки — `apps/docs`.

Цвет вычисляет LabColors, движение исполняет LabMotion. Изменение их
внутреннего механизма выполняется в репозитории владельца.
Figma служит эталоном для чтения; используйте только публичную Community-ссылку.
Приватные Figma identifiers, токены доступа и локальные секреты не включаются
в код, fixtures, логи или описание PR.

## Проверить изменение

Из корня workspace доступны:

```sh
pnpm build
pnpm typecheck
pnpm test
pnpm check
pnpm test:e2e
```

Выбирайте адресные проверки по изменённому поведению. `pnpm test` проверяет
пакеты по очереди и сохраняет ошибку общего запуска, если один из них отказал.
`pnpm check` запускает Biome. Браузерные сценарии требуют установленных
браузеров Playwright; их состав задан в
[конфигурации](apps/docs/playwright.config.ts).

Основной [CI](.github/workflows/ci.yml) запускает smoke-сценарии.
[Полный браузерный прогон](.github/workflows/e2e-full.yml) выполняется отдельно.
Для изменения поведения добавьте проверку, отличающую исходную ошибку
от допустимого соседнего случая. Для визуального изменения сравните
реальный рендер с эталоном.

## Передать изменение

Откройте PR с результатом для пользователя, относящимися проверками
и оставшимися ограничениями. Если меняется публикуемый пакет, оформите
изменение версии через [Changesets](.changeset/) командой `pnpm changeset`.

Код внешнего fork PR автоматически не исполняется в CI Lab UI.
Сопровождающий сначала проверяет изменение и переносит согласованный срез
в ветку репозитория, где выполняются обязательные CI-проверки.

Сообщения об уязвимостях передавайте через [приватный канал](SECURITY.md).
