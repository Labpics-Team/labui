# Шрифт авторского каталога

17 ноября 2026 сопоставлены реальные SVG-контуры Figma и официальные сборки
Geist. Figma не изменялась. `comparison.json` содержит размеры строк,
ошибку границ каждого глифа, покрытие кириллицы, SHA-256 файлов и точные
upstream commits. `comparison.png` и исходный `comparison.svg` показывают
четыре семейства при увеличении 4×; масштаб отдельных runtime-строк не менялся.

Светлый Snackbar, Card Title, Button и Input соответствуют **Geist 1.400**
из [tag 1.4.2](https://github.com/vercel/geist-font/tree/4d655731f83507f0258ce5541c297b6553d5d081).
После нормировки целочисленного viewport экспорта максимальная ошибка границ
глифов составляет 0.018/0.0069/0.0112/0.0143 px соответственно. Это сравнение
границ глифов и анатомии контуров, а не доказательство полного совпадения
каждой кривой. Кириллица содержит все 66 русских букв и 134 символа блока
U+0400–U+04FF в обеих проверенных версиях.

Geist 1.800 меняет реальные ширины: сообщение Snackbar 185.104 → 181.744 px,
Card Title 40.21 → 38.81 px с авторским tracking −0.33. Смена `font-kerning`,
растяжение текста и компенсация отступом не возвращают авторские контуры.
Официальные static/variable 1.800 имеют одинаковые HarfBuzz advances, поэтому
различие web/native формата файла не было причиной.

Тёмная Figma instance сохраняет другой рисунок и метрики при тех же свойствах
font family/weight/size. Ни одна проверенная сборка не воспроизводит одновременно
оба исходных образца; точная версия кэшированного тёмного шрифта не установлена.
Runtime использует **единую 1.400 во всех темах и платформах**, согласованную
с четырьмя авторскими семействами. Переключения шрифта по теме нет.

Метод: fontTools для таблиц, контуров и cmap; HarfBuzz для штатного shaping
при wght 400/500, размере 16/20 и tracking исходного TextNode; Figma REST
`svg_outline_text=true` для текста. OpenType overrides светлых узлов пусты.
Первоначальная гипотеза об отключённых kern/ligatures опровергнута реальными
контурами и заменена сравнением версий шрифта.
