# Native Snackbar — 17 ноября 2026

`SnackbarRenderTest` создаёт CPU `ImageComposeScene` без окна. Перед сохранением
ожидаются Geist и четыре одинаковых кадра. PNG показывают первую позу 5 секунд
и постоянное сообщение без таймера; обе темы, ширину 640/360 dp и системный
масштаб текста 100/125/200%. `*-narrow.png` проверяет телефон: сообщение
сохраняется в одной или двух строках, действие переносится ниже по доступному
месту. Радиус углов следует высоте однострочной капсулы, не всей многострочной
области. При увеличении текста круг растёт вместе с цифрой.

`snackbar-timer-5…1.png` — реальное прохождение пяти состояний. Последняя поза
проверяется по пикселям: danger-сектор сверху слева, справа — пустая область.
Это ловит ошибку направления sweep, которая не видна на полном круге.

Профиль: `packages/tokens/src/components.json.snackbar`, Figma master 6109:6735,
dark 7101:54738, timer 6109:6708. `figma-source.json` — неизменённая read-only
выгрузка PR #242. Native использует тот же профиль, общий Elevated и штатный
small/accent/ghost Button. Figma master показывает позу 4 и Acrylic поверх
изображения; этот набор показывает Solid на ровном фоне, поэтому совпадение
оптики с тем исходным фоном здесь не утверждается.

```powershell
native/compose/gradlew.bat -p native/compose :desktopTest --tests pics.lab.ui.LabSnackbarTimerTest --tests pics.lab.ui.SnackbarRenderTest
```

Пауза и срок проверяются отдельно, а системные взаимодействия и сохранение →
Undo → сохранение → перезапуск — в Native Compose CI. Эти изображения сами
по себе не доказывают прохождение Android/iOS/Orca и не закрывают полный каталог.

Независимое ревью исходного 2e41167 нашло обратное направление дуги и столбец
букв на 360 dp / 200%. Оба замечания проверены по Figma/рендеру и исправлены;
проверка строк и пикселей теперь воспроизводит обе исходные ошибки.

Видеозапись XCTest `44141600996` обнаружила ещё одну регрессию: замерший pending
после Save, затем Snackbar с цифрой «5» менее секунды. Проверка
`aDelayedFirstFrameDoesNotConsumeTheActionDeadline` воспроизводила истечение срока
до первого рендера в CPU-сцене. Теперь таймер ждёт первый draw, окончание entrance
и следующий кадр; этот тест и прежние проверки проходят без локального окна.
Исправленный iOS-сценарий прошёл в CI 44158011723 и 44164544956, включая
save → Undo → save → restart. Причина прежнего единичного задержанного кадра
не установлена; временный sampler удалён после расследования.

PNG повторно отрисованы с единым Geist 1.400 из авторского каталога;
[сравнение четырёх семейств](../fonts-20261117/README.md) объясняет выбор версии.
Семь CPU-проверок с этими файлами шрифта прошли.
