# Geist для Windows

`Geist-Variable.ttf` — исходный прямой вариативный TrueType из
[`vercel/geist-font`, тег `v1.7.2`](https://github.com/vercel/geist-font/tree/v1.7.2),
той же версии релиза, что закреплена в
[`packages/fonts/PROVENANCE.md`](../../../../../packages/fonts/PROVENANCE.md).
Файл переименован из `Geist[wght].ttf`; его содержимое не изменено.

- Исходник: <https://raw.githubusercontent.com/vercel/geist-font/v1.7.2/fonts/Geist/variable/Geist%5Bwght%5D.ttf>.
- Commit тега: `a73329da8fc62afc917f796555202e4997f79b7c`.
- Git blob: `f63f0afc6390323715972b6645115485f37cc9f4`.
- Размер: 169056 байт.
- SHA-256: `73894e0448cae90a92b6c2f8732b7bb9acb7b94c418bff559dad4a18e1de9659`.
- Лицензия: SIL Open Font License 1.1, полный текст в [`OFL.txt`](./OFL.txt),
  скопирован без изменений из `packages/fonts/OFL.txt`.

Таблицы `name` и `fvar` проверены чтением бинарника: семейство `Geist`,
начертание `Regular`, PostScript-имя `Geist-Regular`, единственная ось `wght`
от 100 до 900 с начальным значением 400. Внутреннее поле версии гарнитуры —
`Version 1.800`; номер релиза репозитория — `v1.7.2`. Это разные поля источника.

При обновлении меняйте нативный и веб-ассеты вместе через владельца
`packages/fonts`: сохраняйте общий пин, пересчитывайте хеши и проверяйте
семейство и оси. Нативный рендер этого файла проверяется отдельно от его
происхождения.
