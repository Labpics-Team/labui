# `@labpics/icons` (локальный стаб-мост)

**Временный.** Пакет существует только чтобы import-спецификатор `@labpics/icons`
резолвился внутри воркспейса LabUI, пока реальный пакет не опубликован. Повторяет
паттерн-мост `packages/colors-stub`: тонкая build-free заглушка, не копия реального
движка.

## Чем это НЕ является

- **Не** набор иконок. SVG-исходников здесь нет.
- **Не** сборочный конвейер. `index.js` / `index.d.ts` — рукописные простые файлы,
  скрипт `build` — no-op (`node -e ...`), ровно как у `colors-stub`. Ни `tsup`, ни
  `svgo`, ни `rollup`, ни дерева `src/` — см.
  [`test/no-internal-engine.test.ts`](test/no-internal-engine.test.ts), который роняет
  CI, если что-то из этого вернётся.
- **Не** потребляется ни одним компонентом сегодня. Грепните репозиторий: `@labpics/icons`
  пока никто не импортирует. Компоненты, которым нужна иконка, рендерят собственный
  инлайновый SVG, пока реальный пакет не приедет (учёт по местам вызова —
  [`../../docs/external-deps/lab-icons.md`](../../docs/external-deps/lab-icons.md)).

## Реальный пакет

- Репозиторий: `Labpics-Team/lab-icons` (private) — 444 SVG (Filled + Outline),
  tree-shakeable ESM, `currentColor`, rem-масштабируемая геометрия.
- **Внешний блокер**: на момент этого PR у `lab-icons` собственный `package.json` —
  `"private": true`, ноль тегов/релизов; пакет не ставится ни из одного реестра (npm или
  GitHub Packages). LabUI не может зависеть от него как от реальной зависимости, пока он
  не опубликуется. Это блокер на `lab-icons`, не на LabUI — LabUI не вендорит сюда ни его
  сборочный конвейер, ни SVG-исходники.

## План снятия стаба

1. Когда `@labpics/icons` опубликуется — навести workspace-зависимость на пакет из
   реестра вместо этого стаба.
2. Удалить `packages/icons` (эту директорию).
3. Правок у потребителей не ожидается: из стаба сейчас никто не импортирует.
