# @labpics/adapter-codegen

Приватный dev-инструмент: генерирует тонкие обёртки адаптеров (Vue/Svelte/Solid/Astro)
из единого манифеста, выведенного из исходников `@labpics/ui-core`. В рантайм адаптеров
не попадает.

## Зачем

27 компонентов × 4 фреймворка = 108 файлов. Ручной труд дрейфует от ядра. Манифест —
единый источник истины (SSOT): элемент добавлен в ядро → перегенерация подхватывает
его во всех адаптерах; golden-тест ловит расхождение.

## Как

1. **Анализатор** (`analyze.ts`) читает каждый `packages/core/src/components/*/lab-*.ts`
   через TypeScript AST (не regex) и извлекает: тег + класс (`customElements.define`),
   пропы (`static properties` → имя, атрибут, вид), события (`new CustomEvent`), слоты
   (`<slot>`-паттерны), наследование (`alert-dialog ← dialog`). Внутреннее состояние
   (`{ state: true }`) и нативные `aria-*` в манифест не попадают; `field` — не элемент.
2. **Манифест** (`manifest.generated.json`) — отсортированный список компонентов.
3. **Генераторы** (`generators/*`) строят обёртки из манифеста. Типы пропов — через
   `Pick<LabX, …>` из класса ядра (ноль ручного маппинга осей). Вид проброса
   (атрибут / свойство / булев флаг) — по `PropKind`.

## Команды

```sh
pnpm --filter @labpics/adapter-codegen generate   # перегенерировать манифест + обёртки
pnpm --filter @labpics/adapter-codegen test        # анализатор + golden антидрейф
```
