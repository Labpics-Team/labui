# Повышенный контраст

На области интерфейса задайте `data-contrast="more"`. Значение `normal` сохраняет
эталон даже при системном повышенном контрасте; `auto` следует настройке ОС.
Без атрибута вложенная область наследует контраст предка, а корень следует ОС.
Тема задаётся независимо через `data-theme="light|dark|auto"`. Для JavaScript
доступны `setContrast(element, mode)` и `setTheme(element, theme)` из
`@labpics/ui-core`; сами переключения работают и без JavaScript.

Подключаются `@labui/colors/contract.css`, токены и `@labpics/ui-core/theme.css`.
Системные принудительные цвета (`forced-colors`) остаются отдельным режимом
браузера: `normal` их не отключает.

Цветовой контракт, `theme.css` и `material.css` используются из одного выпуска
LabUI. Генератор владеет внутренними маркерами областей `--_lab-*`; core и материалы
читают этот договор. Старый stylesheet, содержащий только цветовые роли, с новыми
стилями не совместим. Замена численного движка за адаптером сохраняет этот договор.

На этапе сборки `createLabuiEngine().resolve(theme, 'more')` задаёт отдельный набор связей.
Вызов без второго аргумента и значение `normal` сохраняют авторские краски
обычного режима. Эта граница не объявляет готовность всего LabUI по WCAG.

В `labui.config.json` закреплены авторские IC-опоры: Light `#0040DD`, Dark
`#409CFF`, нейтральный тёмный `#000000`. Акцентная подпись и focus сохраняют
свою опору. Общая акцентная заливка получает отдельную вычисляемую цель
Program V3. Цвет назначает LabColors: допустимая опора сохраняется, иначе
движок выбирает ближайшее удовлетворяющее отношениям значение. Primary
остаётся белым. Статические secondary-подписи в `more` непрозрачны: это
устраняет обнаруженное расхождение полупрозрачного текста между браузерами.
В обычном режиме сохраняется авторская opacity `0.722`. В кнопке размера S
вторичная подпись в `more` получает regular weight; M/L уже используют его.

Внутреннее свечение акцентной кнопки в `more` отключено. Наведение и нажатие
показываются затемнением, сохраняя светлую надпись. У Switch дополнительная
граница дорожки и бегунка сохраняет различимость положения; размеры не меняются.

Для текущего среза hard-отношения покрывают основной и вторичный текст на
акцентной заливке, акцентную подпись, focus и нейтральную границу control
на трёх фоновых тонах. Обычная декоративная `border-base` в этом режиме
заменяется существующей непрозрачной primary-краской. Заливка сама по себе
не обязана давать 3:1 к внешнему фону, когда кнопку распознают текст или
контрастная иконка. Необходимые selected/checked и focus cues проверяются
отдельно по их реальному использованию; это не общее исключение для controls.

Область назначения — полный RGB8 box. `maxDelta` ограничивает поиск в метрике
Core; значение `8` в этом срезе не отсекает гамму в проверенном текущем профиле.
Это не допустимое визуальное отклонение. Принятие результата требует сравнения
с эталоном и actual-render. Другой профиль метрики требует пересмотра границы.

Готовый snapshot является единственным источником RGB, alpha и фоновых
композиций. `unsatisfied`, `incomplete` и другие неготовые исходы возвращаются
без полного или частичного набора цветов. Входы копируются при создании engine,
поэтому поздняя мутация вызывающего кода не меняет лениво разрешаемый режим.

Проверки этого среза относятся к номинальным RGB8-композициям Core. Они не
подтверждают непрерывный CSS-композитинг, световые эффекты, переходы, blur,
остальные цветовые семейства, все компоненты или платформы. Округление alpha
в браузере и наблюдаемые состояния проверяются на настоящем рендере отдельно.

Основание области non-text contrast:
[W3C SC 1.4.11, Boundaries](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html#boundaries).
