# FX-контракт Program

**Diátaxis:** reference. Область — новый генератор LabUI и его браузерный FX-стенд.

Colors выдаёт пять glow Paint. `neutral` использует белый источник;
`brand`, `danger` и `warning` — авторскую краску соответствующей темы.
Эти четыре Paint имеют alpha из `authored.glowAlpha` — сейчас `0.522`.
`inverted` использует непрозрачный `invertedMuted` темы.
Шесть `focus-ring` остаются aliases сильных Label. `skeleton-highlight`
использует белый источник и общую alpha `fill-quaternary`.

При миграции 213 → 163 ролей снимаются 50 имён: `subtle`/`bloom`
color/core/alpha для шести прежних glow-семей, их base core/alpha,
а также base `success`/`info`. Смысл пяти сохранённых glow-имён тоже меняется:
они содержат исходный цвет вместе с alpha. Прежний consumer, отдельно
умножавший `*-alpha`, должен перейти на прямое использование Paint.

Прогрессивное свечение строится накоплением одинаковых слоёв. Стенд
`test/fx-render/fx-render.mjs` рисует один, два и три radial-gradient слоя
через CSS `screen`; каждый следующий слой сохраняет все предыдущие.
Форма и смешивание принадлежат браузерному renderer. Отдельные численные
цветовые решения для ступеней отсутствуют. Эффекты Button сохраняют своего
владельца и отдельную проверку.

Проверочная область стенда: Chromium, sRGB PNG, `deviceScaleFactor: 1`,
однородный фон `#0d0d12`, dark-тема, остановленное движение. Из центральных
60% плитки измеряется прежний взвешенный сигнал encoded RGB. До сравнения
сохранены пороги: первый glow-слой выше фона более чем на 1; каждый следующий
выше предыдущего более чем на 0.3; skeleton-highlight выше базы более чем
на 2. Эти числа проверяют видимость в указанной области; контраст WCAG и
восприятие проверяются отдельно. Ошибка условия завершает проверку с отказом.

`--flatten` оставляет по одному слою во всех трёх состояниях и должен нарушить
проверку прогрессии. `--drop=brand` удаляет одну retained Paint;
`--drop-focus=success` проверяет потерю focus. PNG сохраняется и для успешного
рендера, и для этих контрольных отказов. Визуальная приёмка требует отдельного
просмотра настоящего PNG.
