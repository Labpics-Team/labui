# @labui/colors — паспорт бренда labui для движка lab-colors

`labui.config.json` — полный конфиг дизайн-системы labui в формате `ThemeConfig`
границы `@labpics/colors` (`loadConfig(JSON.stringify(config))`).

## Что внутри

Только ИЗМЕРЕННЫЕ якоря идентичности и семантика labui: пер-темная четвёрка
бренда, тройка нейтрали + края, 10 семейств палитры, сентимент-политика,
96 ролей + 2 алиаса, 4 темы. Всё остальное (лестницы, контрасты, подтон,
разведение оттенков) движок выводит контрактами — значений «на глаз» здесь нет.

## Провенанс и защита от дрейфа

- Источник значений: живые замеры Figma «🧪Lab UI (v.1)» (стаб
  `packages/colors-stub/contract.css` несёт их дословно).
- Отпечаток конфига (возвращается `loadConfig`): `1c7f8151f1dfc4da` —
  пин; изменившийся отпечаток = конфиг изменился, проверь осознанность.
- До сноса `labui_reference()` из движка файл регенерируем сериализацией
  эталона; после сноса ЭТОТ файл — единственный носитель labui-семантики.

## Зазоры до зелёного золота (`test/golden-parity.test.mjs`, `it.fails`)

Золотая сверка живого движка со стабом вскрыла три класса (2026-07-02):

1. **Нейтральные core-роли: форма эмиссии.** Стаб несёт их rgba-лестницей
   (`rgb(60 60 67 / 0.722)` — тинт × альфа, полупрозрачность реальна),
   движок — солвер-солидами (`#71717A` ≈ композит стаба в пределах пары LSB).
   Решение поезда: перевод core-ролей на лестницу от нейтрали (меню уже умеет),
   НО у нейтральной рампы СВОИ альфы (0.161 ≠ акцентной @NN-рампы) — снять
   нейтральную рампу отдельными данными позиций.
2. **info-\*-quaternary** отсутствуют в списке исключений разведения — механика.
3. **fx-glow-inverted (light)**: стаб солид без альфы против rgba движка —
   заземлить против Figma (несоответствие стаба или намеренность).
