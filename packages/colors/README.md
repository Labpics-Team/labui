# Цветовая тема LabUI

`@labui/colors` связывает авторские краски LabUI с живым декларативным движком
`@labpics/colors`. При изменении темы, контраста или независимого фона Core
пересчитывает весь Program. Браузер получает согласованный набор CSS-ролей,
сохраняющий авторскую прозрачность и обязательные ограничения.

## Подключить к странице

Подключите `@labui/colors/contract.css` и используемые стили LabUI. Затем:

```ts
import { attachLabuiColors } from '@labui/colors/runtime';

const colors = attachLabuiColors({
  scope: document.documentElement,
  backdrop: document.body,
  canvas: 'authored',
  onState({ state }) {
    // Здесь приложение показывает собственное состояние недоступности.
    document.body.toggleAttribute('data-colors-unavailable', state !== 'ready');
  },
});

await colors.ready;
```

`canvas: 'authored'` выбирает цвет подложки из `themes.<theme>.background` в
`labui.config.json`, включая опоры повышенного контраста. Этот вход сохраняется
в `--lab-canvas-input` независимо от опубликованных ролей. При отзыве результата
его можно снова наблюдать и восстановить тему.

Для внешнего фона передайте его DOM-элемент как `backdrop` и опустите `canvas`.
Поддерживается явно заданная равномерная непрозрачная подложка sRGB8. Если
приложение уже владеет наблюдением, оно может передать `observe()`, возвращающий
`{ kind: 'observed', surface: [r, g, b] }` или `{ kind: 'unknown', reason }`.
Неизвестное наблюдение отзывает управляемые цвета.

Прозрачность основного авторского слоя задаётся опциональным
`themes.<theme>.backgroundOpacity` в конфигурации. При отсутствии поля используется
`1`; `0` означает прозрачный слой. Значение должно быть числом от `0` до `1`.
Источники и alpha остальных красок сохраняются отдельно от готовых фоновых
композиций, которые вычисляет Core.

## Изменение условий и освобождение

Атрибуты `data-theme="light|dark|auto"` и `data-contrast="normal|more|auto"`
наследуются от ближайшего предка, включая host ShadowRoot. Без атрибутов
используются системные настройки. Runtime наблюдает фон и условия в кадрах;
при неизменном входе повторного решения не требуется. Явный `refresh()`
подтверждает точный повтор через Core.

Каждая независимо адаптируемая вложенная область получает своё подключение,
свой `scope` и свой фон. CSS-свойства наследуются в дочерние компоненты обычным
способом; сам stylesheet подключается в Document или ShadowRoot области.
У одной области может быть только один владелец runtime. Для новой декларации
вызовите `dispose()` прежнего подключения, затем передайте `config` новому.
Переданный объект копируется.

`ready` завершается первым результатом после загрузки: проверьте его `state`.
Успешный результат имеет состояние `ready`. Неизвестный фон, несовместимые
требования и отказ исполнения оставляют явное неготовое состояние. До первого
успеха и после отзыва все управляемые CSS-роли замаскированы; частичная тема
не публикуется. Повреждение собственного stylesheet вызывает отзыв и
восстановление полного Program.

`cancel()` отзывает текущие цвета и останавливает наблюдение. `refresh()`
возобновляет работу. `dispose()` отзывает результат, освобождает подключение,
listeners и собственный stylesheet; после него снова действует окружающий
CSS-контракт страницы. Повторное освобождение допустимо. При скрытии страницы
или `pagehide` результат отзывается, при возврате наблюдение возобновляется.
Поздняя загрузка отменённого подключения не заменяет новое состояние.

## Область оценки

Program оценивает объявленные точечные композиции в модели Core. Значения
фоновых тонов и полный набор Paint проходят через один WASM-владелец и один
атомарный CSS-host. Браузерный адаптер не подбирает цвета и не воспроизводит
численные формулы.

Наблюдение цвета DOM-подложки не доказывает свойства всего изображения.
Градиенты, непрозрачность подложки меньше `1`, filter, backdrop-filter,
mix-blend-mode и изменяющая композицию opacity предков дают неизвестный
результат. Эта интеграция не сертифицирует blur, материалы, стекло, тени,
растровые и временные поля либо человеческое восприятие Cleanliness.
Обычный режим сохраняет авторские опоры и выдаёт техническую оценку объявленных
связей; требования повышенного контраста описаны в [CONTRAST.md](CONTRAST.md).

Конфигурация, готовые CSS-артефакты и consumer должны использовать согласованный
выпуск. Наличие этого исходника не подтверждает байты установленного
`@labpics/colors`: проверка доставки включает упакованный WASM и исполнение
реального потребителя.
