# @labui/colors — паспорт бренда labui для движка lab-colors

`labui.config.json` — полный конфиг дизайн-системы labui в формате `ThemeConfig`
границы `@labpics/colors` (`loadConfig(JSON.stringify(config))`).

## Что внутри

Только ИЗМЕРЕННЫЕ якоря идентичности и семантика labui: пер-темная четвёрка
бренда, тройка нейтрали + края, 10 семейств палитры, сентимент-политика,
101 роль + 3 алиаса, 4 темы. Всё остальное (лестницы, контрасты, подтон,
разведение оттенков) движок выводит контрактами — значений «на глаз» здесь нет.

> Поле `sentiment.chroma_fraction` (в конфиге `1.0`): на движке `0.5.0`
> ИНЕРТНО — потолок хромы не двигает. На `0.6.0` оно поднимает потолок гаммы
> (раскроет насыщенные якоря вроде `#FF3B30`). Примечание живёт здесь, а не в
> `labui.config.json`: JSON комментариев не держит.

## Тонкий паспорт (BL-007) — два файла, две роли

С движком `@labpics/colors ≥0.6` словарь ролей/алиасов раскрывается пресетом,
а паспорт несёт только измеренные якоря. Отсюда два файла:

- **`labui.config.thin.json`** — КАНОНИЧЕСКИЙ источник (~180 строк): `preset:
  "labui"` + brand + neutral + palette + sentiments + themes; массивы
  `roles`/`aliases` ОПУЩЕНЫ (движок раскрывает их пресетом). Генератор
  (`generate-contract.mjs`) по умолчанию читает его.
- **`labui.config.json`** — полный ЭТАЛОН тождества (~1236 строк): те же якоря
  плюс словарь ролей/алиасов целиком. Остаётся в репо, потому что грузится
  ЛЮБЫМ движком (в т.ч. опубликованным 0.5.0) и служит опорой сверки.

Тождество (`test/thin-identity.test.mjs`) доказывает ЖИВЬЁМ и относительно
(тонкий против полного, без хардкода): `loadConfig(тонкий).fingerprint ===
loadConfig(полный).fingerprint` и `generateContract(тонкий) ===
generateContract(полный)` байт-в-байт. Отпечаток по построению один — потому
`PASSPORT_FINGERPRINT` не меняется, само тождество и есть доказательство.

Пока движок `< 0.6` (опубликованный 0.5.0 отвергает тонкий с `invalid_config:
missing field \`roles\``), гейт тождества ЧЕСТНО пропускается (причина — в имени
теста) и автоматически включается на 0.6.0 по фиче-детекту `engineSupportsPreset`,
без правки теста. Золотая сверка и гейт дисциплины при этом остаются на полном
эталоне — зелёные на обоих движках.

## Провенанс и защита от дрейфа

- Источник значений: живые замеры Figma «🧪Lab UI (v.1)» — заморожены дословно
  в `packages/colors-stub/figma-reference.css` (якорь золотой сверки);
  `contract.css` — генерируемый артефакт движка, не источник.
- Отпечаток конфига (возвращается `loadConfig`): см. `PASSPORT_FINGERPRINT`
  в `engine.mjs` — единый источник (шапка `contract.css` регенерируется из
  него). Изменившийся отпечаток = конфиг изменился, проверь осознанность.
  В рукописной прозе литерал отпечатка не держим — он дрейфует.
- Регенерация файла — только воспроизводимым эмиттером движка
  (`cargo run -p labcolors-wasm --example emit_passport`; отпечаток — в
  stderr). После сноса `labui_reference()` из движка ЭТОТ файл —
  единственный носитель labui-семантики.

## Золото (`test/golden-parity.test.mjs`) — боевой гейт

Сверка живого опубликованного движка со стабом — обычные тесты (не
`it.fails`): каждое значение стаба воспроизведено или исключено
законом-причиной из `EXPECTED_DIVERGENCES`. Новое расхождение роняет сборку.
Действующие классы исключений: лейблы/border-strong — солвер от фактического
фона (статика стаба = до-законный язык); info-* — разведение оттенка с
брендом; fx-glow-inverted — заземлённый Figma-недосмотр (солид вместо @52);
fill-neutral — провизорный литерал стаба (деривация — открытая задача);
Zero-токены — невидимость эмитится отсутствием; control-bg — компонентная
поверхность (маппинг поезда); fx-skeleton-base — наследует fill-quaternary
(тёмная дельта @12→@16 — правка старого языка).
